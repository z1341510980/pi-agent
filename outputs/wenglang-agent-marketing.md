## 五、长文案（官网 / README / 发布公告完整版）

# wenglang-Agent：一个会给自己写插件的 Agent

## 我们做了一件「危险」的事

我们把 Agent 的方向盘交给了它自己。

在 wenglang-Agent 里，功能不是产品经理排期排出来的，而是**你用出来的**。当你发现「这里要是有个 XX 就好了」，你不需要去提 issue、不需要学插件开发——你只需要告诉它。

它会：

1. **理解需求** —— 把你的自然语言变成功能设计
2. **自己编程** —— 写出符合插件规范的代码
3. **自己安装** —— 插件即插即用，热重载即时生效
4. **自我验证** —— 跑通即用，不行就改

这不是「自定义配置」，这是**自我迭代**。第一天和第三十天的 wenglang-Agent，是两个工具。

## 为什么底座能撑住这种进化？

因为 wenglang-Agent 从第一行代码起，就是按「一切皆插件」设计的：

| 能力 | 说明 |
|------|------|
| **插件化架构** | 工具、路由、UI 面板、会话、提示词模板——没有什么是不能成为插件的 |
| **服务容器** | 插件间 provide/get 依赖注入，能力自由组合、互相增强 |
| **声明式管理** | `config/plugins.yml` 一处声明，启用/禁用/隔离/传参全搞定 |
| **热重载** | 本地与 npm 插件改完即生效，零重启 |
| **Realm 隔离** | 不信任的插件关进独立数据库与上下文，进化在安全轨道上进行 |
| **多源插件** | builtin / local / npm 三种来源，生态即插即用 |

底座越干净，长出来的东西越强壮。

## 两大官方插件：底座之上的第一次「生长」

### 📖 小说助手：让长篇不再崩坏

写长篇的都知道，杀死一部小说的不是文笔，是**失控**——设定前后矛盾、伏笔有去无回、冲突不了了之。

小说助手用一套完整的叙事引擎解决这个问题：

- **叙事概念建模**：故事线、场景、故事线推进、冲突、线索分层管理，每个概念边界清晰，剧情矩阵全局可视
- **多角色质量流水线**：Director 规划、Reviewer 审稿、Reviser 修订，像编辑部一样逐章把关
- **结构化章纲与节拍**：基于 submit 工具的结构化协议输出，章纲、节拍由 Schema 严格校验，杜绝模型「自由发挥」导致的漂移
- **跨场景记忆**：候选故事线被持续追踪，人工确认后转正，没有一条线索能悄悄消失

百万字之后，它还记得第一章埋下的那颗雷。

### 🎨 无限画布：把大脑摊在桌面上

思维不该被 A4 纸框住。

无限画布是一张没有边界的工作台：想法、素材、Agent 生成的内容自由排布、任意连接。创意的火花不再是聊天记录里滚走的一行字，而是画布上一个可以反复观察、组合、回溯的节点。

写作时摊开故事线，做方案时摊开思路，和 Agent 一起把混乱变成结构。

## 谁该用它？

- **创作者**：写长篇的人，需要小说助手的叙事引擎和无限画布的发散空间
- **重度 AI 用户**：受够了功能等待的人，你的工具该听你的了
- **开发者**：想要一个干净的插件化 Agent 底座，在上面种自己的生态
- **所有人**：想体验「工具随你成长」是什么感觉的人

## 六、技术向文案（给开发者 / 技术社区）

**wenglang-Agent：把「写插件」这件事也交给 Agent**

我们基于 Electron + Fastify + AG-UI 协议构建了一个插件化 Agent 桌面应用。架构借鉴 DeepSeek Harness 的 Cordis 理念：

- `Plugin` 接口 + `PluginContext` 运行时上下文，`setup`/`teardown` 全生命周期管理
- `provide`/`get`/`dependsOn` 服务容器，插件间依赖注入
- 声明式 `plugins.yml` 配置，`builtin`/`local`/`npm` 三种插件来源（npm 包以 `wenlang-agent-plugin-` 前缀命名）
- ESM 时间戳重载实现热重载，teardown → 重载 → 恢复配置 → 重启
- Realm 隔离模式：独立 SQLite、独立数据目录、独立事件订阅
- AG-UI 协议全双工流式通信，支持 steer（运行中干预）、fork（对话分叉）、navigate（历史回溯）

杀手级特性：**Agent 能自己编写并安装插件**——底座的插件 API 足够干净，干净到 LLM 可以直接按规范生成代码、热重载进运行时。自我迭代不是口号，是架构的自然结果。

内置小说助手插件是一套严肃的多 Agent 叙事工程：故事线/场景/冲突/线索域模型、Director-Reviewer-Reviser 工具集、基于闭包捕获式 submit 工具的结构化输出（拒绝 `responseFormat: 'json'` 文本解析漂移）。

欢迎来读代码，更欢迎来写插件——或者，让 wenglang-Agent 替你写。
