# AI 写小说工具 · 抖音直播创意策划方案（3 套差异化）

> 交付对象：copywriter / image-creator / video-generator
> 渠道：抖音 ｜ 核心目标：涨粉引流（精准粉丝积累优先，直播/短视频内预埋关注与引流钩子）
> 产品核心卖点：帮用户生成、续写、润色小说；写作提效、灵感不卡壳、新手也能写出完整故事
> 目标受众：抖音小说推文/短剧解说创作者、网文小白作者、卡文人群、微短剧爱好者

---

## 方案一：现场创作秀 ——「AI 陪写搭子」

**1. 方案名称 + 一句话定位**
现场创作秀「AI 陪写搭子」：把 AI 写作变成一场"观众点题、实时成稿"的创作真人秀，用爽感和悬念拉停留、拉关注。

**2. 主播 / 账号人设**
- 人设标签：「AI 陪写搭子」——一个话痨、会接梗、像朋友一样的 AI 应用达人。
- 性格：亲切、反应快、懂网文套路（霸总/重生/甜宠/悬疑都能接），偶尔被读者"整活"反将一军。
- 视觉记忆点：永远戴着发光耳机，旁边立着一块"今日点题板"。

**3. 直播核心玩法 / 栏目设计（每场流程骨架）**
- 开场钩子（0-5min）：甩一个热门题材悬念开头，弹幕投票"今天写哪个题材"。
- 现场成稿（5-20min）：用 AI 现场生成世界观 + 人设 + 第一章开头，边写边解说提示词套路。
- 读者点题续写（20-40min）：弹幕决定剧情走向（"男主该不该黑化？""女主掉悬崖还是被救？"），实时续写。
- 高潮反转（40-55min）：AI 生成一段"神转折"高潮，配合悬念卡点。
- 收尾引流（55-60min）：抽奖送"爆款开头模板包"，引导关注+进粉丝群。

**4. 涨粉引流钩子设计**
- 关注理由：关注后私信/粉丝群每日领取"一个爆款开头模板"（持续价值）。
- 评论区互动：固定话题"你想看什么题材？下场我现写"；弹幕点题决定剧情。
- 粉丝群/资料引流话术："扣 1 进群领《100 个网文提示词库》""关注后群内每周更新 AI 写作秘籍"。

**5. 配套短视频内容方向（直播预热 + 日常涨粉）**
1. 《3 秒 AI 生成霸总开头》——纯炫技卡点，引好奇。
2. 《读者点题我现写》系列合集——截取直播高光续写片段。
3. 《卡文救急现场》——用户投稿卡文段落，AI 现场救活。
4. 《AI 写 vs 人写》对比——同一题材两段，制造话题。
5. 《幕后提示词揭秘》——露出"原来这样写 prompt 才出爽文"。

**6. 视觉风格方向建议（给视觉同事）**
- 整体调性：赛博国风 × 科技感真人秀，年轻、酷、有沉浸感。
- 主色：暗紫 `#2A1B4D` + 霓虹青 `#00E5D0`（强调/光标）。
- 辅色：暖粉 `#FF6FB5`（互动高亮）、墨黑底 `#0E0A1A`。
- 字体气质：科技感书法标题（毛笔笔触 + 发光描边），正文用无衬线。
- 画面元素关键词：流动光粒子、悬浮键盘、墨水晕染成字、霓虹"点题板"、耳机发光。

**7. 直播脚本结构大纲（时间轴骨架）**
| 时间 | 环节 | 口播要点 |
|------|------|---------|
| 0-5min | 开场钩子 | "今天写啥？弹幕定！三选一题材先投起来" |
| 5-20min | 现场成稿 | 边用 AI 生成边讲提示词："看，这样一个人设就立住了" |
| 20-40min | 读者点题续写 | "男主黑化扣 1，洗白扣 2——听你们的" |
| 40-55min | 高潮反转 | 生成神转折，卡悬念："猜结局？关注下场揭晓" |
| 55-60min | 收尾引流 | 抽奖 + "进群领今日模板，明天同时间开写" |

## 方案二：小白教学 ——「网文写作教练」

**1. 方案名称 + 一句话定位**
小白教学「网文写作教练」：手把手教零基础用户用 AI 写出人生第一本小说，把"我写不出来"变成"我也能写"。

**2. 主播 / 账号人设**
- 人设标签：「被催更逼疯的网文老手 / 写作教练」——严厉但暖心，专治卡文。
- 性格：毒舌点评 + 真诚鼓励，擅长把复杂套路拆成"傻瓜步骤"。
- 视觉记忆点：身后一块"卡文急救榜"，学员投稿贴满便签。

**3. 直播核心玩法 / 栏目设计（每场流程骨架）**
- 痛点共鸣开场（0-5min）："你是不是也卡在第 3 章？开头写了 8 遍？"引发评论区刷屏。
- 套路拆解（5-20min）：拆解一个爆款结构（如"黄金三章""爽点节奏"）。
- AI 一步步演示（20-40min）：从 0 到 1 用 AI 生成第一章，每步停顿讲"为什么这样写"。
- 学员投稿点评（40-52min）：念粉丝投稿段落，现场用 AI 润色改造。
- 作业打卡 + 引流（52-60min）：布置"今日写作小作业"，打卡进群抽奖。

**4. 涨粉引流钩子设计**
- 关注理由：关注领《小白写作 7 天训练营资料包》（结构化价值钩子）。
- 评论区互动："把你的卡文难题打在公屏，下场抽 3 个我帮你改"。
- 粉丝群/资料引流话术："关注后扣'训练营'自动发资料""群内每日打卡互相催更"。

**5. 配套短视频内容方向（直播预热 + 日常涨粉）**
1. 《新手最常犯的 3 个写作错误》——痛点直击，收藏率高。
2. 《用 AI 10 分钟写出第一章》——教学干货，强转化关注。
3. 《爽点 / 金句到底怎么写》——拆解 + 案例。
4. 《人设模板直接抄》——给懒人可套用模板。
5. 《写作避坑指南》——平台违规、水文雷区提醒。

**6. 视觉风格方向建议（给视觉同事）**
- 整体调性：明亮轻快、陪伴感、手账教科书风，亲和、无距离感。
- 主色：暖橘 `#FF8A3D` + 奶白 `#FFF7EC` 底。
- 辅色：草绿 `#7CCB5A`（对勾/完成）、浅棕 `#C8A27A`（便签）。
- 字体气质：圆体 / 手写感标题，正文用易读无衬线，像"朋友写的笔记"。
- 画面元素关键词：便签贴、手写箭头、教科书分栏、进度条、可爱插画小人、咖啡杯。

**7. 直播脚本结构大纲（时间轴骨架）**
| 时间 | 环节 | 口播要点 |
|------|------|---------|
| 0-5min | 痛点共鸣 | "卡文不是你笨，是没掌握结构——今天教你" |
| 5-20min | 套路拆解 | "黄金三章就三件事：立人设、抛冲突、给钩子" |
| 20-40min | AI 演示 | "跟我一步步来，从空白页到第一章成稿" |
| 40-52min | 投稿点评 | "念投稿、现场改，看 AI 怎么救这段" |
| 52-60min | 作业引流 | "今天作业：写 200 字开头，进群打卡抽奖" |

## 方案三：小说推文变现 ——「推文变现操盘手」

**1. 方案名称 + 一句话定位**
小说推文变现「推文变现操盘手」：教用户用 AI 批量生产小说推文 / 短剧解说，跑通抖音变现路径，用"真金白银"吸引想赚钱的人。

**2. 主播 / 账号人设**
- 人设标签：「推文变现操盘手」——干练、数据党、敢晒收益截图。
- 性格：理性、结果导向，说话有底气和案例支撑，不爱鸡汤爱方法论。
- 视觉记忆点：背景常驻"今日收益 / 爆款数据"大屏，手机一亮就晒。

**3. 直播核心玩法 / 栏目设计（每场流程骨架）**
- 晒案例数据开场（0-5min）：亮一条爆款推文播放 + 收益截图，抛"这条为什么爆"。
- 爆款拆解（5-20min）：拆解一条推文的结构（选题—开头钩子—高潮截取—挂载）。
- AI 全流程演示（20-40min）：用 AI 生成推文文案 + 选段，演示"一条推文 20 分钟产出"。
- 剪辑挂载演示（40-52min）：现场演示剪辑 + 小程序/书籍挂载动作（不违规前提下讲路径）。
- 招募引流（52-60min）：招募"推文合伙人/实训营"，引导关注 + 进群领选题库。

**4. 涨粉引流钩子设计**
- 关注理由：关注领《推文爆款选题库 500 题》+《平台规则避坑清单》。
- 评论区互动："你做过推文吗？赚到没？评论区报个数""想学扣 666"。
- 粉丝群/资料引流话术："关注后扣'选题'发你爆款库""群内每天晒一条可抄的爆款结构"。

**5. 配套短视频内容方向（直播预热 + 日常涨粉）**
1. 《一条推文我赚了多少》——收益截图 + 拆解，强吸引力。
2. 《AI 生成推文文案全流程》——从选书到成稿演示。
3. 《爆款开头 3 秒公式》——可复用方法论。
4. 《短剧解说怎么挂载变现》——路径科普（合规表述）。
5. 《推文避坑 / 平台规则红线》——实用保命指南。

**6. 视觉风格方向建议（给视觉同事）**
- 整体调性：商务科技感、专业、可信、有"搞钱"气质。
- 主色：深蓝 `#0B1F3A` + 金 `#F5C451`（收益/高亮）。
- 辅色：青蓝 `#2E8BFF`（数据/链接）、灰白 `#F2F4F7` 底。
- 字体气质：利落无衬线（如思源黑体 Bold），数字用等宽体强调。
- 画面元素关键词：数据曲线、手机屏幕、收益大屏、箭头流程图、图表卡片、键盘+钞票符号（克制使用）。

**7. 直播脚本结构大纲（时间轴骨架）**
| 时间 | 环节 | 口播要点 |
|------|------|---------|
| 0-5min | 晒数据钩子 | "这条推文 3 天带来 X，今天拆给你看" |
| 5-20min | 爆款拆解 | "爆款=选题对+开头狠+挂载准，逐条讲" |
| 20-40min | AI 演示 | "看 AI 怎么 20 分钟产出一条可发推文" |
| 40-52min | 挂载演示 | "剪辑完这样挂，路径讲清楚不踩雷" |
| 52-60min | 招募引流 | "想系统学扣 666，进群领选题库+实训" |

## 附：整体品牌视觉方向建议

- **品牌统一基底**：三套方案共用一套"AI × 文字"超级符号——**发光笔尖从键盘长出、化作文字流**，作为账号头像、直播间贴片、短视频尾版的统一记忆点。
- **品牌主色系统（跨方案）**：以"暗夜写作"为底（深紫黑 `#141026`），用**青色 `#00E5D0`** 作为 AI 科技统一色，各方案在此基础上叠加自己的强调色（方案一霓虹粉、方案二暖橘、方案三金色），既统一又区分栏目。
- **字体规范**：标题统一用"科技书法体"（毛笔感 + 发光描边）建立品牌识别；正文/数据用无衬线，保证可读性。
- **统一话术钩子**：所有短视频/直播结尾统一 slogan「写作不卡壳，AI 当搭子」，强化品牌心智。
- **统一尾版**：短视频结尾固定 2 秒品牌尾版（发光笔尖符号 + slogan + 关注箭头），提升关注转化。

## 附：30 天抖音发布节奏建议（供主理人排期）

> 原则：短视频日常种草涨粉，直播集中转化关注与互动；前期测内容，中后期稳定栏目标签。

- **短视频节奏**：第 1–30 天，工作日（周一至周五）每日 1 条（共约 22 条），周末可不发或发"直播高光剪辑"。
  - 第 1–7 天：以方案一"炫技/点题"和方案二"小白痛点"混发，测试哪类完播/涨粉更好。
  - 第 8–21 天：跑出优势方向后，按 6:3:1 比例分配（教学干货 6 / 创作秀 3 / 变现 1），持续涨粉。
  - 第 22–30 天：加大方案三"变现"占比（引流高意向人群），为后续转化蓄水。
- **直播节奏**：
  - 第 1–2 周：每周 2 场（建议周四晚 20:00、周日 15:00），以方案一"创作秀"+ 方案二"小白教学"试水。
  - 第 3–4 周：提升至每周 3 场（周二 20:00 教学、周四 20:00 创作秀、周日 15:00 变现/招募），固定栏目标签培养追看习惯。
  - 直播前 1–2 天发"预告短视频"，直播后次日发"高光切片"二次引流。
- **节点提示**：可借抖音"小说推文"相关热点话题（如 #小说推文 #短剧解说 #写作变现）打标签，提升自然流量。
