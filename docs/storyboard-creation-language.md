# 分镜创作语言格式说明

## 一、格式定位

这套格式是一种面向视频生成模型的单镜头导演提示词规范。

它不是传统文学剧本，也不是单纯的画面提示词，而是将以下内容整合到同一份镜头文档中：

- 剧情目标
- 人物身份与外观锁定
- 场景空间关系
- 时间轴动作
- 表演心理变化
- 摄影机运动
- 光线与材质
- 同期声音
- 连贯性约束
- 禁止生成事项
- 下一镜头衔接状态

核心作用是让模型明确知道：

> 这一镜要讲什么、人物如何变化、镜头如何拍、哪些内容绝对不能改变。

## 二、整体结构

推荐将每个镜头拆分为以下十三个部分：

```text
〖镜头编号〗
〖目标时长〗
〖生成目标〗
〖参考素材职责〗
〖未提供素材｜由模型按剧情生成〗
〖主体与空间关系〗
〖事件脚本〗
〖Dialogue Ledger｜唯一对白源〗
〖摄影 / 表演 / 光影〗
〖声音〗
〖保持一致〗
〖硬性约束〗
〖最终落点 / 衔接目标〗
```

## 三、各模块作用

### 1. 镜头编号

用于标识镜头在整场戏中的位置。

格式建议：

```text
S01-01｜胡成、冯安街边饮酒
```

命名规则：

```text
S场次编号-镜头编号｜镜头内容概括
```

示例：

```text
S01-01｜两人街边饮酒
S01-02｜胡成展示发财凭证
S01-03｜冯安试探胡成
```

镜头标题应同时说明主要人物、主要动作和主要场景。不建议只写“酒铺”“街道”这类没有叙事信息的标题。

### 2. 目标时长

明确生成视频的总时长：

```text
〖目标时长〗
10秒
```

如果时间轴较复杂，也可以增加精度要求：

```text
目标时长：10秒
时间轴精度：按0.1秒级理解
```

目标时长必须与后面的事件脚本完全一致。

### 3. 生成目标

这是整份提示词的剧情总纲，需要回答三个问题：

- 这段视频发生了什么？
- 观众应该理解人物之间的什么关系？
- 这段视频最终要把剧情推进到哪里？

建议先写整体剧情目标，再写本段真正的戏剧核心：

```text
〖生成目标〗
本段表现A与B表面保持客气，实际已经存在矛盾。

本段核心不是动作本身，而是：
A做出某个细微反应 → B产生误解 → B情绪升级 → 某个动作形成关系压力。

无对白，通过表演、视线和声音完成戏剧信息。

本段为场景首段，无上一镜尾帧需要继承。
```

“本段核心不是……”这一写法可以防止模型把注意力错误放在普通动作上。

### 4. 参考素材职责

用于规定不同参考图分别负责什么。核心原则是：

> 每张参考素材只能负责明确的内容，不能互相越权。

推荐写法：

```text
{{Mixed 1}} = CHAR-02 冯安｜唯一身份外观权威。
只负责冯安的脸、骨相、年龄感、发型、胡须、体型、服装结构与颜色。

{{Mixed 2}} = CHAR-01 胡成｜唯一身份外观权威。
只负责胡成的脸、骨相、年龄感、发型、胡须、体型、服装结构与颜色。

{{Mixed 3}} = LOC-01 长安街边酒铺｜唯一空间与基础时辰权威。
负责建筑、道路、街景、空间纵深和基础光线状态。
```

建议区分以下权威类型：

```text
CHAR = 人物身份权威
LOC = 场景空间权威
PROP = 道具权威
TIME = 时间、天气、光线权威
STYLE = 视觉风格权威
```

必须同时写出禁止事项：

```text
不得从人物参考图继承背景。
不得从场景参考图生成新的主角脸。
不得改变固定人物服装。
不得让不同参考素材之间互相覆盖身份信息。
```

### 5. 未提供素材

用于列出允许模型自由生成的内容：

```text
〖未提供素材｜由模型按剧情生成〗
普通粗陶酒壶；
两只粗陶酒碗；
街道上的普通行人；
符合时代背景的环境细节。
```

这一部分应明确：

- 哪些内容可以自由生成
- 哪些内容只属于背景层
- 数量是否有限制
- 是否禁止新增剧情角色
- 道具是否有固定数量

例如：

```text
背景路人可以具有身份和服饰差异，但全部属于环境层。
不得生成新的主要人物。
不得让路人与主角发生剧情性交互。
```

对于重要道具，应直接锁定数量：

```text
桌面除一只酒壶和两只酒碗外，不增加其他食物。
```

### 6. 主体与空间关系

这是镜头构图和人物连续性的基础。建议明确写出：

- SUBJECT A和SUBJECT B分别是谁
- 人物位于画面哪一侧
- 前后关系
- 坐姿或站姿
- 身体朝向
- 视线方向
- 道具与人物的位置关系
- 背景所在位置
- 全段不能发生的空间变化

示例：

```text
胡成 = SUBJECT A / IMMUTABLE IDENTITY。
冯安 = SUBJECT B / IMMUTABLE IDENTITY。

胡成位于画面左侧偏前。
冯安位于画面右侧偏后。
两人坐在同一张低木桌两侧。
低木桌位于两人之间，形成明确关系屏障。

两人全段不换座、不起身、不瞬移。
```

这一部分可以解决模型常见的连续性问题：

- 人物左右位置互换
- 前后关系改变
- 道具位置漂移
- 人物突然起身
- 场景空间重新生成
- 背景人物进入主叙事

## 四、事件脚本格式

### 1. 按时间轴拆分

事件脚本是整个格式的核心。推荐使用以下结构：

```text
起始时间–结束时间
主体：
动作与表演：
摄影要求：
声音：
结束状态：
```

示例：

```text
0.0s–2.5s
主体：冯安。

冯安拿起酒壶，给胡成面前的酒碗缓慢添酒。
酒液连续、真实地流入陶碗。

胡成不低头看酒，始终看着冯安。

摄影机保持双人关系可读，只做极轻微靠近。

结束状态：
酒已添好，胡成仍盯着冯安。
```

### 2. 每个时间段必须写清楚四件事

每一段都应明确：

- 谁是主要动作主体
- 发生了什么动作
- 动作应该如何表演
- 这一段结束时人物处于什么状态

“结束状态”尤其重要，因为它负责连接下一时间段。

### 3. 动作数量必须受到控制

对关键动作使用数量锁定：

```text
冯安只倒一次酒。
胡成只完成一次明确饮酒。
胡成只完成一次重放酒碗。
动作只发生一次。
```

这样可以避免模型重复动作或自行增加戏剧动作。

### 4. 用负面描述限制表演方向

不能只写“喝酒”，还需要说明不要怎么喝：

```text
饮酒动作自然，不豪饮，不仰头灌酒，不表现成烂醉。
```

不能只写“生气”，需要限定情绪强度：

```text
不是愤怒瞪眼，而是自尊敏感、略带醉意的人产生了被轻视的念头。
```

## 五、心理变化写法

这套格式的重点不是描述动作数量，而是描述动作背后的心理变化。

建议使用以下结构：

```text
外部动作
→ 细微表情
→ 对方观察
→ 错误理解或心理变化
→ 可见动作
→ 关系状态改变
```

本例的心理链条是：

```text
冯安添酒
→ 冯安克制陪笑
→ 胡成捕捉到笑意
→ 胡成将陪笑理解成轻视
→ 胡成重放酒碗
→ 两人之间形成明显压力
```

这是整段镜头的叙事骨架。

最终兑现关系必须写成明确的因果链：

```text
冯安陪笑
→ 胡成误解
→ 酒碗重落桌
→ 冯安笑意消失
```

## 六、Dialogue Ledger

用于规定这一镜头唯一允许出现的对白来源。

如果无对白，应明确写：

```text
〖Dialogue Ledger｜唯一对白源〗
本段无对白。

胡成：不说话。
冯安：不说话。

禁止生成任何额外台词、旁白、字幕或清晰口型。
背景路人只允许模糊不可辨识的市井交谈声。
```

这一部分可以防止模型自行生成台词、旁白、字幕、明确口型或背景人物可辨识对白。

如果有对白，应将对白集中写在这一模块，其他部分只描述动作和情绪，不重复编写台词。

## 七、摄影、表演与光影

这一部分规定镜头应该如何拍，而不是剧情发生什么。

### 摄影内容

应说明：

- 景别
- 机位高度
- 画面方向
- 是否移动
- 移动速度
- 是否切镜
- 是否使用特写
- 是否保持人物关系可读

示例：

```text
全段优先保持同一个3/4双人关系镜头。
摄影机位于街道一侧的人眼高度。
只允许非常轻微的真实摄影机呼吸感和缓慢靠近。
不机械滑轨，不环绕人物，不使用正反打。
```

### 表演内容

应说明：

- 情绪来源
- 情绪强度
- 表情变化
- 动作幅度
- 禁止的戏剧化表现

示例：

```text
冯安：因为两家有旧怨而谨慎，不想惹事。
胡成：薄醉使自尊更加敏感，把普通陪笑解释成轻视。

禁止电视剧式瞪眼。
禁止夸张冷笑。
禁止大幅皱眉。
禁止醉酒摇晃。
禁止拍桌怒吼。
```

### 光影内容

应说明：

- 时间段
- 主光源
- 色温关系
- 天空状态
- 是否允许夜景
- 空气质感
- 材质真实性

示例：

```text
太阳接近落山但天尚未黑。
暖夕光与初起蓝调同时存在。
不能变成深蓝夜景。
人物皮肤、胡须、布料、木桌、陶器保持真人实拍材质。
```

## 八、声音设计

声音部分建议按三个层次书写。

### 1. 声音总原则

```text
无BGM。
只使用同期现场声。
```

### 2. 环境底噪

```text
傍晚街道远处模糊人声；
自然脚步；
衣料摩擦；
极轻晚风；
远处偶尔经过的木轮或马蹄声。
```

### 3. 关键声音事件

按照时间轴写出声音与动作的对应关系：

```text
0.0–2.5s：
酒液进入陶碗的细小声音。

5.0–7.3s：
轻微饮酒与吞咽声。

7.3–10.0s：
陶碗与厚木桌接触产生一次沉闷、清楚的“咚”。
```

声音设计需要标明哪一个声音是本段的戏剧重点：

```text
酒碗落桌声是本段最重要的声音事件。
之后不人为静音，环境声继续存在，但人物之间形成心理停顿。
```

## 九、保持一致

这一部分负责跨镜头连续性锁定。需要固定：

- 人物身份
- 人物脸部
- 服装
- 发型
- 胡须
- 人物左右位置
- 场景建筑
- 道具数量
- 时间和光线
- 动作次数
- 上一镜或下一镜的衔接状态

示例：

```text
胡成始终坐画面左侧。
冯安始终坐画面右侧。
两人之间始终是同一张低木桌。

酒壶全段只有一只。
酒碗固定两只。
冯安只倒一次酒。
胡成只完成一次明确饮酒。
胡成只完成一次重放酒碗。
```

如果是场景第一镜，应写：

```text
本段为场景首段，无上一镜尾帧需要继承。
```

如果需要承接上一镜，应写清楚：

```text
继承上一镜人物坐姿、道具位置、光线方向和人物左右关系。
```

## 十、硬性约束

硬性约束是模型不能违反的底线。建议采用短句，一条一项：

```text
禁止新增第三名主要人物坐到酒桌旁。
禁止路人与两名主角发生剧情性交互。
禁止把场景变成室内酒楼。
禁止夜景化。
禁止碗破裂、翻倒、飞出桌面。
禁止夸张醉态。
禁止自行生成对白。
禁止随机切镜。
```

硬性约束应优先覆盖以下风险：

- 身份错误
- 场景错误
- 时代错误
- 道具错误
- 动作错误
- 镜头错误
- 声音错误
- 剧情错误

## 十一、最终落点与衔接

每个镜头都需要有明确的最终落点。

最终落点不是简单描述最后一帧，而是说明：

- 人物关系发生了什么改变
- 谁获得了主动权
- 谁意识到什么
- 下一镜头从什么状态继续

本例的最终落点可以整理为：

```text
〖最终落点 / 衔接目标〗
胡成已经从“同席饮酒”进入“准备炫耀自己的发财本事”的状态。
冯安意识到胡成的情绪已经发生变化。
画面直接为S01-02衔接。
```

## 十三、这套格式的核心写作原则

### 1. 先写戏剧目的，再写动作

不要只写：

```text
两个人喝酒。
```

应写成：

```text
通过一次克制的陪笑和一次重放酒碗，表现两人从表面客气转为关系紧张。
```

### 2. 先锁定身份和空间，再描述变化

人物、位置、服装和场景是稳定层；表情、动作、情绪和声音是变化层。写作时要避免让变化层影响稳定层。

### 3. 时间轴必须有前后因果

每一段都应该回答：

```text
前一段发生了什么？
这一段谁做了什么？
对方如何理解？
下一段为什么会发生？
```

### 4. 用“结束状态”控制模型衔接

时间段之间不能只靠时间连接，还要靠状态连接：

```text
结束状态：胡成已经注意到冯安的笑。
下一段：胡成开始把这个笑理解成轻视。
```

### 5. 用“禁止”代替模糊提醒

不要只写：

```text
表现克制。
```

应进一步写：

```text
禁止瞪眼、怒吼、拍桌、醉酒摇晃和夸张皱眉。
```

### 6. 每个镜头只保留一个主要戏剧转折

本例的唯一主要转折是：

```text
陪笑被误解，酒碗重落桌面。
```

不要为了增加“电影感”而加入额外特写、换角度、路人冲突或新的对白。

## 十四、对本例的结构化提炼

```text
镜头功能：
建立两人表面客气、实际互有戒心的关系。

视觉结构：
固定3/4双人中景，胡成左前，冯安右后，低桌形成关系屏障。

表演结构：
冯安克制陪笑。
胡成观察并误解。
胡成薄醉，自尊敏感。
胡成重落酒碗。
冯安笑意消失。

声音结构：
环境声持续。
酒液声建立生活感。
吞咽声建立人物状态。
“咚”声完成权力转折。

剧情落点：
胡成准备炫耀。
冯安意识到气氛改变。
进入下一镜。
```

最终，这套分镜语言可以概括为：

> 素材负责身份，空间负责连续性，时间轴负责动作，表演负责心理，声音负责转折，硬性约束负责防止模型越界。
