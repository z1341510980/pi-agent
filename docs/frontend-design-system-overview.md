# 前端设计体系重构总结

## 变更概要

将原有的 `docs/FRONTEND_DEVELOPMENT.md`（14 章，~2000 行）重构为 **`docs/FRONTEND_DESIGN_SYSTEM.md`**（11 章 + 附录），
以**设计体系**的视角重新组织内容。

## 核心变化

### 新增内容
1. **设计语言**（第一章）— 完整色彩系统（含实际 CSS 变量值）、排版系统、间距网格、圆角体系
2. **参考风格分析** — 主流 AI 助手（WorkBuddy/Cursor/VS Code）的设计趋势总结
3. **组件 API 文档** — 每个组件的 Props 接口、内部状态、CSS 结构
4. **当前实现状态标注** — 每个功能点标注 ✅（已实现）/ ⬜（规划）/ 进行中状态
5. **F1 当前进度** — 与真实代码对齐的实现状态表

### 重构重点
- **原 §1（概述）** → 分散到"设计语言"+"设计理念"+"参考风格"
- **原 §3（全局布局）** → 第二章"布局系统"，增加 CSS Grid 具体代码和响应式断点
- **原 §4（对话工作台）** → 第三章"组件体系"+ 第四章"页面设计"，每个组件独立文档
- **原 §7（状态管理）+ §8（通信层）** → 第六章+第七章，补充真实代码片段
- **原 §10（动画）+ §11（响应式）+ §12（性能）** → 第八章+第九章+第十章
- **原 §13（路线图）** → 第十一章，增加 F0 完成状态和 F1 进行中状态的精确标注

### 保留内容
- 信息架构（原 §2）→ 分散到页面设计和组件体系
- 消息类型矩阵 → 3.3.3 节
- 设置中心设计 → 第五章规划
- AG-UI 事件到 UI 映射 → 附录 A
- 快捷键全表 → 9.3 节
- 性能基线 → 10.3 节
- 开发路线图 → 第十一章（带当前进度）

## 关键设计决策
| 决策 | 理由 |
|------|------|
| 不从零重写，而是"重构" | 原有内容质量很高，需要重新组织而非丢弃 |
| 新增"设计语言"章节 | 原有文档缺少视觉设计的系统化论述 |
| 标注实现状态 | 让团队成员知道哪些已做、哪些规划 |
| 保留旧版参考 | 兼容性考虑，团队可以对比阅读 |
