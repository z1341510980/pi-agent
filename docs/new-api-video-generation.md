# 创建视频生成任务

New API 视频生成接口，支持文生视频和图生视频。接口返回任务 ID，可通过视频生成任务状态接口查询进度。

## 创建任务

### 请求

```http
POST /v1/video/generations
Authorization: Bearer sk-xxxxxx
Content-Type: application/json
```

使用 Bearer Token 认证。`Authorization` 请求头格式为 `Bearer <token>`。

### 请求体

请求体格式为 `application/json`。

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `model` | string | 模型或风格 ID | `kling-v1` |
| `prompt` | string | 文本描述提示词 | `宇航员站起身走了` |
| `image` | string | 图片输入，支持 URL 或 Base64 | `https://example.com/image.jpg` |
| `duration` | number | 视频时长，单位为秒 | `5` |
| `width` | integer | 视频宽度 | `1280` |
| `height` | integer | 视频高度 | `720` |
| `fps` | integer | 视频帧率 | `30` |
| `seed` | integer | 随机种子 | `20231234` |
| `n` | integer | 生成视频数量 | `1` |
| `response_format` | string | 响应格式 | `url` |
| `user` | string | 用户标识 | `user-1234` |
| `metadata` | object | 扩展参数，例如 `negative_prompt`、`style`、`quality_level` | `{}` |

### cURL 示例

```bash
curl -X POST "https://your-new-api.example/v1/video/generations" \
  -H "Authorization: Bearer sk-xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-v1",
    "prompt": "宇航员站起身走了",
    "duration": 5,
    "width": 1280,
    "height": 720,
    "fps": 30,
    "n": 1,
    "response_format": "url",
    "user": "user-1234"
  }'
```

## 响应

### 200 成功

返回视频生成任务信息。

```json
{
  "task_id": "abcd1234efgh",
  "status": "queued"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 ID |
| `status` | string | 任务状态，创建后通常为 `queued` |

### 400 请求参数错误

```json
{
  "error": {
    "message": "string",
    "type": "string",
    "param": "string",
    "code": "string"
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `error.message` | string | 错误信息 |
| `error.type` | string | 错误类型 |
| `error.param` | string or null | 相关参数 |
| `error.code` | string or null | 错误代码 |
