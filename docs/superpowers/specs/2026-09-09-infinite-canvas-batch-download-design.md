# Infinite Canvas 批量下载选中节点设计

## 背景

`infinite-canvas-plugin` 已支持节点多选、单个图片/媒体下载以及画布 JSON 导出。现在需要在底部功能栏增加批量下载入口，让用户把选中的不同类型节点一次性打包下载。

## 目标

- 在底部功能栏提供“批量下载选中”操作。
- 将选中的可下载节点转换为文件并打包为一个 ZIP。
- 支持图片、视频、音频、文本类节点和配置节点。
- 保持现有单节点下载和画布 JSON 导出行为不变。

## 非目标

- 不下载未选中的节点。
- 不把分组节点本身作为文件下载。
- 不新增服务端接口或 Electron 主进程 IPC。
- 不改变节点内容的持久化格式。

## 交互设计

底部 `CanvasToolbar` 在 `selectedCount > 0` 时显示“批量下载选中”按钮，位置与删除选中操作相邻。无选中节点时不显示。

点击按钮后：

1. 读取当前选中的节点。
2. 收集可下载内容并生成 ZIP。
3. 以 `<画布标题>-selected.zip` 触发本地下载。
4. 下载过程中按钮禁用，避免重复打包。
5. 完成后显示成功数量；单个文件失败时继续处理，并在结果提示中列出失败项。

没有任何文件成功生成时，不下载空 ZIP，而是显示错误提示。

## 节点到文件映射

| 节点类型 | 文件内容 | 文件扩展名 |
| --- | --- | --- |
| `image` | `metadata.images` 中的全部图片；没有批量结果时使用 `metadata.content` | 按 Blob MIME 类型推断 |
| `video` | `metadata.content` | 按 Blob MIME 类型推断 |
| `audio` | `metadata.content` | 按 Blob MIME 类型推断 |
| `text`、Prompt、Agent 结果及其他文本扩展节点 | 节点文本内容 | `.txt` |
| `config` | 节点 metadata 序列化为格式化 JSON | `.json` |
| `group` | 跳过 | 无 |

图片节点的多张结果使用 `<标题>-1`、`<标题>-2` 等序号后缀。文件名使用节点标题，清理 Windows 非法字符、空白标题和路径分隔符，并通过统一的重名计数避免 ZIP 内文件覆盖。

## 技术方案

新增轻量 ZIP 依赖 `fflate`，在 renderer 侧完成打包：

- 使用已有 `resolveDownloadBlob` 获取图片、视频和音频资源，兼容 `data:` 地址和代理后的外部 URL。
- 文本和 JSON 直接转换为 `Blob` 或字节数组。
- 由批量下载模块负责节点展开、文件名生成、错误收集和 ZIP 构建。
- 使用现有 `downloadUrl` 下载最终 ZIP Blob。

建议把可测试的收集/命名逻辑放在独立模块中，React workspace 只负责读取选中节点、调用异步资源解析和展示状态。

## 错误处理

- 没有选中节点：按钮不可见，不执行操作。
- 节点没有有效内容：跳过并记录节点标题。
- 远程资源获取失败：跳过当前文件，继续处理其他文件。
- 所有文件均失败或仅选中了分组：不生成 ZIP，展示可读错误。
- 至少一个文件成功：生成 ZIP，并将失败项合并到完成提示中。

## 测试范围

- 文件名清理和重名处理。
- 图片节点单图、多图和空内容展开。
- 各节点类型的文件映射，分组节点跳过。
- 文本/JSON 内容生成。
- ZIP 包包含预期文件名和内容。
- `CanvasToolbar` 在有选中节点时显示入口，并正确传递点击和禁用状态。
- 桌面端相关 Vitest 测试和 web 类型检查。

## 验收标准

- 多选图片、视频、音频、文本和配置节点后，点击功能栏按钮能下载一个 ZIP。
- ZIP 内文件可正常解压，媒体文件内容不被损坏，文本和 JSON 可读。
- 同名节点不会互相覆盖。
- 某个资源下载失败不会阻断其他节点打包。
- 无可下载节点时不会产生空 ZIP，并给出明确提示。
- 原有单节点下载、JSON 导出、删除选中和节点选择行为不回归。
