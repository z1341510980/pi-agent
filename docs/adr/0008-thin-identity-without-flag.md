# 薄身份直接落地模板，不设 thinAgentIdentity 回滚开关

日期：2026-08-11 状态：已采纳（对统一方案 §13.1 的书面偏差）

背景：统一方案 §13.1 要求 thinAgentIdentity flag 默认关闭、可回旧 system。实际上薄身份（职责+边界+输出+工具权限）已在 role-*.md 模板中直接落地，且旧"厚身份"提示词在模板改造中已被替换，仓库内不存在可切换回去的旧版本。

决策：不实现 thinAgentIdentity 开关（实现一个没有旧路径可切的开关等于死开关）；薄身份的正确性由 identity-contract.ts 防漂移校验器（AGENT_IDENTITY_MARKERS + 20000 字符上限）与 prompt-protocol 一致性测试守卫；回滚方式为 git revert role-*.md 模板变更。

理由：开关的价值在于存在两条可切换的路径；仅存一条路径时，开关只会制造"看似可回滚"的假象。防漂移测试提供了比开关更强的日常保护。

反方观点：违反 §13.1"所有开关默认关"的纪律。以本 ADR 留痕偏差与替代回滚手段；若未来重建厚身份模板，应补回真实双路径开关。
