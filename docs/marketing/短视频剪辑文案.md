# 短视频剪辑文案：AI 小说创作推广视频

> 视频时长：45 秒 | 平台：抖音 / 视频号 | 目的：引流直播间 + 吸引创作者
> 配套：直播话术流程.md 的引流切片

---

## 一、视频定位

| 项目 | 内容 |
|------|------|
| 视频主题 | 我让 5 个 AI 像编辑部一样写小说 |
| 时长 | 45 秒 |
| 平台 | 抖音（主）、视频号（同步） |
| 目标受众 | 网文作者、AI 工具爱好者、副业探索者 |
| 核心目标 | 引流直播间 / 引导关注 / 引流私域 |
| 转化钩子 | 评论区置顶"AI 写小说"领体验入口 |
| 视频调性 | 节奏快、有干货感、不浮夸 |

### 内容核心三句话

1. 痛点：写小说卡文、伏笔忘、自审难
2. 方案：5 个 AI Agent 像编辑部协作
3. 证据：拿出一章已写的小说 + 矩阵视图

---

## 二、视频结构（5 段式）

| 段落 | 时间 | 时长 | 目的 | 核心 |
|------|------|------|------|------|
| 1 钩子 | 0-3s | 3s | 抓眼球 | 反差开场 + 字幕暴击 |
| 2 痛点 | 3-10s | 7s | 共鸣 | 灵魂三问快剪 |
| 3 展示 | 10-30s | 20s | 价值证明 | 矩阵视图 + Agent 跑动 |
| 4 证据 | 30-40s | 10s | 可信 | 读小说原文 + 拆伏笔 |
| 5 CTA | 40-45s | 5s | 行动 | 关注 + 评论区入口 |

## 三、详细分镜脚本

### 镜头 1：钩子（0-3s）

| 项目 | 内容 |
|------|------|
| 画面 | 黑屏 → 突然出现"5 个 AI 在写小说"白字 → 切到 pi-agent 桌面端矩阵视图快速缩放 |
| 字幕 | 我让 5 个 AI 像编辑部一样写小说 |
| 配音 | "我让 5 个 AI，像编辑部一样，写了一本小说。" |
| 音效 | "咚"重低音 + 键盘敲击声 |
| 节奏 | 0-1s 黑屏静默，1-2s 字幕弹出配音起，2-3s 画面切入 |
| 备注 | 前 3 秒必须出现"5 个 AI"和"写小说"两个关键词 |

### 镜头 2：痛点快剪（3-10s）

| 项目 | 内容 |
|------|------|
| 画面 | 三段快切：1) 写作者对着空白文档抓头发 2) 文档里满屏"……" 3) 自己读稿皱眉 |
| 字幕 | 卡文 / 忘伏笔 / 自审难 |
| 配音 | "写到一半卡文，前面埋的伏笔自己忘了，写完自己看不出毛病。" |
| 音效 | 每个痛点配一个"叮"故障音 |
| 节奏 | 每个痛点 2 秒，三段共 7 秒 |
| 备注 | 痛点画面用真实场景，不用网图 |

### 镜头 3：方案揭示（10-15s）

| 项目 | 内容 |
|------|------|
| 画面 | pi-agent 工作台全景 → 镜头推进到 Agent 面板 → 5 个 Agent 头像/标签依次亮起 |
| 字幕 | 导演 / 写手 / 审稿 / 修订 / 记忆 |
| 配音 | "所以我做了一个系统，5 个 AI Agent 分工：导演规划，写手执笔，审稿挑刺，修订改稿，记忆管理员保证前后不穿帮。" |
| 音效 | 每个 Agent 亮起配一个"嗒"电子音 |
| 节奏 | 5 个 Agent 每个 1 秒亮起 |
| 备注 | Agent 名称用中文标签，别用英文 |

### 镜头 4：矩阵视图展示（15-22s）

| 项目 | 内容 |
|------|------|
| 画面 | 矩阵视图横向滚动 → 镜头推进到某个伏笔格子 → 高亮显示伏笔从第 3 章延伸到第 8 章回收 |
| 字幕 | 横轴章节 / 纵轴角色伏笔冲突 / 一眼看清全局 |
| 配音 | "最牛的是这个矩阵视图，横轴是章节，纵轴是角色、伏笔、冲突。你埋的雷在哪、什么时候收，一目了然。" |
| 音效 | 矩阵滚动时配低频电子音，伏笔高亮时"叮"一声 |
| 节奏 | 滚动 3 秒，高亮 4 秒 |
| 备注 | 这是视频的"啊哈时刻"，画面要慢，让观众看清 |

### 镜头 5：Agent 实时跑动（22-30s）

| 项目 | 内容 |
|------|------|
| 画面 | 创建流程界面 → Director 输出文字流式滚动 → Checkpoint 弹窗 → 点击通过 → Writer 接力输出 |
| 字幕 | AI 自己规划 / 关键节点你拍板 / 自己写自己改 |
| 配音 | "点一下开始，导演先规划，关键节点停下来等你确认，通过之后写手上场，写完审稿接上，全程不用你动手。" |
| 音效 | 文字滚动配打字机声，Checkpoint 弹窗配"叮咚" |
| 节奏 | Director 3 秒，Checkpoint 2 秒，Writer 3 秒 |
| 备注 | 这段是流程证明，节奏要快，用 1.5 倍速回放 |

### 镜头 6：读小说原文（30-37s）

| 项目 | 内容 |
|------|------|
| 画面 | 切到第 3 章正文，镜头从上往下滚动，配合配音朗读的文字高亮 |
| 字幕 | 叶明远握着玉佩靠在碎石后面...像是有人把烙铁贴在了掌心 |
| 配音 | （朗读）"叶明远握着玉佩靠在碎石后面，手指能感觉到玉佩在变温...玉佩猛地烫了一下，像是有人把烙铁贴在了掌心。" |
| 音效 | 朗读时背景音切为低沉的悬疑配乐 |
| 节奏 | 7 秒读两段，节奏不能拖 |
| 备注 | 这段是可信度证明，必须真读真字，不能糊弄 |

### 镜头 7：拆伏笔证据（37-40s）

| 项目 | 内容 |
|------|------|
| 画面 | 矩阵视图定位第 3 章 → 三个伏笔格子依次高亮 → 信息差标签亮起 |
| 字幕 | 3 个伏笔 / 信息差 / 读者知道角色不知道 |
| 配音 | "这一章埋了 3 个伏笔，还藏了一个信息差：读者知道主角有外挂，反派不知道。这就是后续张力的来源。" |
| 音效 | 每个伏笔高亮配"叮"音 |
| 节奏 | 3 秒，快节奏 |
| 备注 | 这段证明 AI 不只是写字，还能做结构设计 |

### 镜头 8：CTA 收尾（40-45s）

| 项目 | 内容 |
|------|------|
| 画面 | 切回人脸（或头像）+ pi-agent logo → 屏幕出现"评论 AI 写小说 领体验入口" |
| 字幕 | 评论"AI 写小说" / 领体验入口 + 创作手册 |
| 配音 | "想知道 AI 怎么像编辑部一样协作？评论区扣'AI 写小说'，我把体验入口和创作手册发给你。" |
| 音效 | 结尾"咚"重低音 + 关注音效 |
| 节奏 | 5 秒，最后 1 秒画面定格 |
| 备注 | CTA 必须明确，给一个具体动作 + 具体回报 |

## 四、剪辑步骤（从素材到成片）

### 步骤 1：素材准备（30 分钟）

**必需素材**

| 素材 | 来源 | 时长 | 用途 |
|------|------|------|------|
| pi-agent 桌面端录屏 | OBS 录制 | 5 分钟 | 镜头 3/4/5/7 |
| 第 3 章正文截图 / 滚动录屏 | pi-agent 内 | 1 分钟 | 镜头 6 |
| 矩阵视图录屏 | pi-agent 内 | 2 分钟 | 镜头 4/7 |
| Agent 跑动录屏 | 预跑一次录下来 | 3 分钟 | 镜头 5 |
| 人脸口播 | 手机 / 摄像头 | 30 秒 | 镜头 1/8 |
| 痛点场景素材 | 自己拍 / 素材库 | 10 秒 | 镜头 2 |

**录屏参数**

- 分辨率：1920×1080
- 帧率：30fps
- 格式：MP4（OBS 默认）
- 录屏时关闭通知、关闭无关窗口

### 步骤 2：粗剪（20 分钟）

工具：剪映（手机 / 电脑版均可）

1. 新建项目，导入所有素材
2. 按分镜脚本顺序排列素材到时间线
3. 每个镜头先按目标时长粗切（不精修）
4. 全片先拼出 45 秒骨架，检查节奏
5. 检查点：
   - [ ] 总时长 45 秒（±3 秒）
   - [ ] 8 个镜头都到位
   - [ ] 钩子镜头在 3 秒内出现关键词
   - [ ] CTA 镜头在最后 5 秒

### 步骤 3：精剪（30 分钟）

1. **配音录制**：先录完整配音（45 秒），按段落切开
2. **对齐画面**：每个镜头的画面与配音对齐，配音是节奏主轴
3. **节奏卡点**：在每个镜头切换处打标记，配卡点音效
4. **关键帧动画**：
   - 镜头 1：字幕"砰"地放大出现
   - 镜头 4：矩阵视图缓慢推进 + 伏笔格子高亮闪烁
   - 镜头 5：文字流式滚动效果（用剪映的"打字机"特效）
5. **检查点**：
   - [ ] 配音与画面同步，不抢词不拖词
   - [ ] 每个镜头切换有卡点
   - [ ] 关键画面停留足够（矩阵视图至少 3 秒）

### 步骤 4：字幕与特效（20 分钟）

1. **字幕样式**：
   - 字体：思源黑体 Bold（或抖音常用的"圆体"）
   - 字号：屏幕高度的 1/15
   - 颜色：白色 + 黑色描边（保证可读性）
   - 位置：屏幕中下偏上（避开抖音底部按钮区）
2. **关键词高亮**：把"5 个 AI""编辑部""矩阵视图""伏笔""信息差"用黄色或红色突出
3. **特效**：
   - 镜头 1：黑屏弹出字幕用"闪现"特效
   - 镜头 2：痛点三连用"故障"转场
   - 镜头 4：矩阵高亮用"放大镜"或"聚光灯"效果
   - 镜头 8：CTA 字幕用"打字机"特效

### 步骤 5：配乐与音效（15 分钟）

**配乐结构**

| 时间段 | 配乐类型 | 音量 |
|--------|----------|------|
| 0-3s | 悬疑开场（低频鼓点） | 30% |
| 3-10s | 紧张节奏（卡点） | 25% |
| 10-30s | 科技感电子乐（节奏明快） | 20% |
| 30-40s | 悬疑低沉（朗读背景） | 15% |
| 40-45s | 收尾鼓点 + 关注音 | 30% |

**音效清单**

| 时间点 | 音效 | 来源 |
|--------|------|------|
| 0-1s | "咚"重低音 | 剪映音效库 |
| 1-3s | 键盘敲击声 | 剪映音效库 |
| 3/5/7s | "叮"故障音（痛点切换） | 剪映音效库 |
| 11-15s | "嗒"电子音（Agent 亮起） | 剪映音效库 |
| 22-30s | 打字机声 | 剪映音效库 |
| 37-40s | "叮"高亮音 | 剪映音效库 |
| 45s | "咚"收尾 | 剪映音效库 |

### 步骤 6：调色与画面优化（10 分钟）

1. **整体色调**：科技感偏冷色（蓝绿调），朗读段切暖色（橙黄调）
2. **录屏画面**：增强对比度，让矩阵视图格子清晰可见
3. **人脸画面**：提亮 + 磨皮（剪映美颜 30%）
4. **文字清晰度**：所有字幕加描边 + 阴影，保证小屏幕可读

### 步骤 7：导出（5 分钟）

**导出参数**

| 参数 | 设置 |
|------|------|
| 分辨率 | 1080×1920（竖屏）|
| 帧率 | 30fps |
| 码率 | 8-10 Mbps |
| 格式 | MP4 (H.264) |
| 音频 | AAC 128kbps |

**导出检查**

- [ ] 全屏播放一遍，无卡顿无错位
- [ ] 字幕全部可读
- [ ] 配音清晰，配乐不抢人声
- [ ] 文件大小 30-50MB（抖音推荐）

## 八、剪辑避坑清单

| 坑 | 表现 | 解决 |
|----|------|------|
| 前 3 秒没钩子 | 完播率 < 20% | 钩子镜头必须含"5 个 AI"+"写小说" |
| 配音太慢 | 用户划走 | 配音语速 1.2 倍，剪掉所有气口 |
| 画面停留太久 | 节奏拖 | 每个镜头 ≤ 5 秒，矩阵视图除外 |
| 字幕太小 | 手机看不清 | 字号 = 屏幕高度 / 15 |
| 配乐太大 | 听不清配音 | 配音 100%，配乐 ≤ 30% |
| 录屏糊 | 矩阵看不清 | 录屏分辨率 1080p + 增强对比度 |
| CTA 不明确 | 转化低 | CTA 必须给具体动作 + 具体回报 |
| 没有卡点 | 节奏散 | 镜头切换处必须配卡点音效 |
