# 抖音深度演示视频：矩阵 / 编排 / 自动审核

> 规格：1.5–3 分钟深度演示（主稿按 2'20" 设计，附伸缩说明）
> 目标：引流私域（评论区扣关键词）
> 账号阶段：新号冷启动（<1000 粉）
> 核心卖点：①矩阵让实体有迹可循 ②章节情节可编排 ③多角色自动审核

---

## 零、先说清楚这条视频的风险

新号 + 2 分钟以上 = 完播率天然吃亏。抖音给新号的初始流量池只有 200–500 播放，能不能进下一个池子，几乎只看三件事：**3 秒停留率、完播率、评论数**。

所以这条视频的三条硬规则：

1. **前 3 秒不许出现工具名、不许自我介绍。** 只许出现一个问题或一个反差画面。
2. **每 30 秒必须有一个"信息闭环"。** 观众在任何一秒划走，都能拿走一点东西，而不是"看了个寂寞"。
3. **18 秒处必须埋留人钩。** 明确告诉观众"后面还有一个更狠的"，否则 2 分钟视频撑不到第 40 秒。

## 一、视频定位

| 项目 | 内容 |
|------|------|
| 一句话主题 | 让小说的每个人、每个伏笔，在第几章出现过，一眼看到 |
| 时长 | 2'20"（可伸缩至 1'40" / 3'00"） |
| 目标人群 | 写过 10 万字以上长篇的人（网文作者、大纲党、设定控） |
| 不讨好的人群 | 想"一键生成"的爽文玩家 —— 这条视频会劝退他们，这是对的 |
| 核心转化 | 评论区扣「矩阵」→ 私信发体验入口 + 实体管理手册 |
| 调性 | 演示为主、不喊麦、不吹"AI 替代作家" |

### 三个卖点对应的用户利益（文案必须落到利益，不是功能）

| 功能 | 用户心里的原话 |
|------|----------------|
| 矩阵实体追踪 | "写到 20 万字，前面埋的雷我自己都忘了" |
| 情节可编排 | "AI 替我把剧情决定了，我成了改稿的" |
| 多角色自动审核 | "写完自己读着别扭，但说不出哪不对" |

| 音效 | 画面切入配一次"嗖"转场 |
| 备注 | **这段是完播率的命**。8 秒不能多，悬念不能剧透，说完立刻进卖点 |

### 段落 4｜卖点一：矩阵（0:26–1:02）

| 项 | 内容 |
|----|------|
| 画面 | 矩阵横向滚动 → 停在"赵岩"这一行 → 展开子轨道 → hover 弹出卡片显示 before/after |
| 字幕 | 横轴是章节 / 纵轴是故事里所有的"东西" / 十类 / 出现过的地方都在一条线上 |
| 口播 | "先说第一个，这个矩阵。<br>横轴是章节，从第一章一路排下去。纵轴不是人物表，是这个故事里所有的'东西'——角色、伏笔、冲突、线索、地点、势力、物品、信息差，一共十类。<br>每一个东西在哪一章出现过、那一次它变成了什么样，全躺在一条轨道上。<br>你点开这条看：第七章，赵岩从'察觉'变成了'派人监视'。谁改的、为什么改，一条不落。<br>还有我最满意的一点：AI 在正文里碰上一个它不认识的名字，不会偷偷给你编个人物出来，它会扔进待审区等你点头。你的人物表，永远是你说了算。" |
| 音效 | 子轨道展开"嗒"，hover 卡片"叮" |
| 备注 | 这是全片"啊哈时刻"，节奏要慢，hover 卡片至少停 3 秒让观众看清 |

### 段落 5｜卖点二：编排（1:02–1:32）

| 项 | 内容 |
|----|------|
| 画面 | 节拍表 → 点开某一章行内编辑 → 把"戏剧功能"从「升温」改成「喘息」→ 改一句摘要 → 保存 → 启动创作 |
| 字幕 | AI 替你写 ≠ AI 替你决定 / 未来六章的节拍，你拉开就能改 |
| 口播 | "第二个，编排。<br>AI 写小说最招骂的一点是什么？它替你把剧情决定了，你变成改稿的。<br>这个不这样。它先给你一张节拍表，未来六章，每一章是铺垫、是假胜利、还是中点反转，你拉开就能改。<br>你觉得第三章不该在这儿转折，把戏剧功能从'升温'改成'喘息'，写一句你要的走向，保存。<br>然后 AI 按你这个节拍去写。你是在排戏，不是在许愿。" |
| 音效 | 下拉菜单"嗒"，保存"叮" |
| 备注 | 最后一句"排戏不是许愿"是全片金句，字幕要单独放大一拍 |

### 段落 6｜卖点三：自动审核（1:32–2:08）

| 项 | 内容 |
|----|------|
| 画面 | 启动创作 → Director 输出叙事任务 → 检查点弹窗 → 点通过 → Writer 流式出正文 → Reviewer 十维评分卡 → 问题列表（带 S1/S2 分级）→ Reviser 打补丁 |
| 字幕 | 导演定任务 → 写手出稿 → 审稿十维挑刺 → 修订精确打补丁 / 最多两轮，不无限循环 |
| 口播 | "第三个，自动审核。<br>我点开始。导演先出一份叙事任务，写完停下来等我点头——这是第一个卡点，AI 不替你拍板。<br>我通过，写手出正文。<br>写完审稿上场。它不是打个分就完了，它按十个维度挑：一致性、人设、伏笔状态、冲突变化、节奏、信息控制、钩子、文风……每条问题还分级，从致命到轻微。<br>看这条：'电钻采石写得太顺，缺成本和风险。'这话说得对。<br>然后修订出手，按这条意见在原文里做精确替换——只改这几句，不碰你的剧情。<br>改完复检，还不行整章重写，但最多两轮，不无限循环。<br>最后记忆把这一章谁出场了、哪个伏笔埋下了，全部回填进矩阵，下一章接着用。" |
| 音效 | 检查点"叮咚"，问题列表逐条"嗒"，补丁替换"唰" |
| 备注 | 十维不要念完，念 5–6 个就切画面，全念会拖。问题分级 S1 致命那个要特写 |

### 段落 7｜CTA（2:08–2:20）

| 项 | 内容 |
|----|------|
| 画面 | 切回矩阵全景 → 左下角出现关键词卡片 |

## 四、发布文案

### 4.1 标题（三选一，建议 A）

**A（推荐｜痛点反问式）**

> 写到第 20 章，你还记得第 3 章埋的雷吗

**B（好奇式）**

> 我让 AI 写完一章，又让另外三个 AI 挑它的毛病

**C（数字干货式）**

> 2 分钟演示：小说里每个人、每个伏笔，在第几章出现过一眼看到

> 新号别用"我开发了一个 AI 小说工具"当标题 —— 自嗨，点击率通常不到 2%。

### 4.2 视频描述

> 长篇写到十几万字，最难受的不是写不出来，是记不住：前面埋的伏笔、人物关系的走向、哪章出过什么东西。
>
> 这条视频演示三件事：
> 1. 一张「章节 × 实体」矩阵，让角色、伏笔、冲突、线索、地点、物品等十类东西的每一次出现都有据可查；
> 2. 章节节拍可以自己编排，AI 按你定的戏剧功能写，不是它替你决定剧情；
> 3. 写完自动进多角色审核，十个维度挑问题、按意见精确修订，最多两轮不无限循环。
>
> 工具叫 pi-agent。想要体验入口的，评论区扣「矩阵」。

### 4.3 话题标签（分层打，别只堆大词）

| 层级 | 标签 | 作用 |
|------|------|------|
| 大流量（蹭曝光，2 个就够） | `#AI写作` `#AI工具` | 进大池子，但新号基本沉底 |
| 中量级（主战场，3 个） | `#网文创作` `#小说创作` `#写作工具` | 真正跑量的地方 |
| 精准小词（新号机会，4 个） | `#长篇小说写作` `#小说大纲` `#伏笔` `#网文作者` | 竞争小，容易进前排 |

```
#AI写作 #AI工具 #网文创作 #小说创作 #写作工具 #长篇小说写作 #小说大纲 #伏笔 #网文作者
```

> 新号冷启动的核心技巧：**大词给算法看，小词给流量。** 只打大词，你会被千万级流量池淹掉。

## 五、评论区运营（转化主战场）

### 5.1 置顶评论

> 扣「矩阵」两个字，我把 pi-agent 体验入口 + 《长篇实体管理手册》一起发你。已发的回复下接着扣就行，一个个来。

### 5.2 关键词为什么选「矩阵」

| 备选 | 互动成本 | 来的质量 | 结论 |
|------|---------|---------|------|
| **矩阵**（主推） | 低（2 字） | 高 —— 冲这个功能来的人，是真被戳中的 | ✅ 用这个 |
| AI写小说 | 中（5 字） | 中 —— 量大但杂 | 备用 |
| 扣 1 | 极低 | 低 —— 羊毛党多，私域转化差 | ❌ 不建议 |

**换词规则**：发布 48 小时后，如果「矩阵」带来的评论 < 15 条，把置顶评论改成「扣 1，发你入口」冲互动量，接受质量下降。

### 5.3 自问自答（用小号或朋友号，各发 1 条）

- "这个能写都市 / 悬疑吗？还是只能修真？"
- "跟直接让 ChatGPT 写有什么区别？"
- "要钱吗？"

> 目的不是造假，是**给真人一个开口的理由**。冷启动阶段评论区真空，没人敢当第一个。

### 5.4 前 10 条评论回复原则

1. **每条必回**，回复也算互动量，能加权。
2. **用提问收尾**："你写到多少万字了？" —— 把单向回复变成双向对话，评论楼层会变高。
3. **不发链接**。抖音会限流。统一话术："已私" / "发你了" / "看主页简介"。
4. 前 2 小时每 10 分钟刷一次，新号的前 20 条评论决定进不进下一个流量池。

## 八、数据复盘指标（新号现实目标）

| 指标 | 合格线 | 优秀 | 说明 |
|------|--------|------|------|
| 播放量 | ≥ 1000 | ≥ 5000 | 新号第一轮，破千就算进了第二个池子 |
| 完播率 | ≥ 25% | ≥ 35% | 2 分钟以上视频，25% 是及格线 |
| 3 秒停留率 | ≥ 50% | ≥ 65% | 不达标就是钩子问题，重剪前 5 秒 |
| 评论数 | ≥ 15 | ≥ 40 | 冷启动最关键的加权项 |
| 扣关键词数 | ≥ 10 | ≥ 25 | 真实转化 |
| 涨粉 | ≥ 20 | ≥ 60 | 顺带的 |

**复盘三个问题**：

1. 完播率在第几秒开始掉？→ 那一段就是废段，下次砍掉。
2. 评论里问得最多的是什么？→ 那就是第 2 条视频的主题。
3. 扣关键词的人里，有几个真去体验了？→ 决定这个系列要不要继续。
