# 第一部分：镜头清单

## 0. 素材盘点（开工前 10 分钟先做这个）

先把你已有的演示录屏拖进剪映，按下面的清单切段。缺的镜头看「缺口补救」列，不要现去补拍。

| 素材 | 是否必需 | 缺口补救方案 |
|------|---------|-------------|
| 矩阵视图横向滚动录屏 | 必需 | 截图 + 关键帧放大推镜（见剪辑手法 C5） |
| 矩阵子轨道展开 + hover 卡片录屏 | 必需 | 截图 + 放大推镜 + 画中画 |
| 节拍表行内编辑录屏 | 必需 | 分 3 张截图，每张 2 秒，中间加"嗒"音效硬切 |
| Agent 跑动录屏（Director→Writer→Reviewer） | 必需 | 无替代，必须补录。提前预跑一次 |
| 已写正文一屏 | 可选 | 用 Word / 记事本打开 md 文件翻拍 |
| 人脸口播 | 不需要 | 全程字幕驱动，不露脸完全成立 |
| 痛点实景 | 不需要 | 用文字动效 + 录屏代替（见 L3–L5） |

**录屏参数**：1920×1080 横屏录（桌面应用是横屏），后期放进竖屏时间线时**上下留黑或用背景模糊填充**，不要强行裁切——矩阵横向拉开才看得清。

# 第二部分：如何剪辑

## A. 工程设置

| 项 | 值 |
|----|-----|
| 分辨率 | 1080×1920（竖屏 9:16） |
| 帧率 | 30fps |
| 序列预设 | 剪映「抖音竖屏」 |
| 横屏录屏处理 | 缩放到宽度 100%，上下用**同色背景模糊**填充，不要裁切 |
| 主轨道 | 画面全部放主轨，不要多轨叠加（后期改节奏方便） |

## B. 时间线搭建（按顺序做，别跳步）

**第 1 步：铺画面骨架（15 分钟）**

按 L1→L25 顺序把素材拖上主轨，每段先按镜头表时长**粗切**。不用管精确，先把 140 秒的骨架拉出来。

**第 2 步：录配音（10 分钟）**

**先录完整配音，再对画面**——这是关键。配音是节奏主轴，画面迁就声音，反过来会剪到崩溃。

- 语速 1.2 倍，全片约 630 字，控制在 2'10"–2'25"
- 剪掉所有气口和"那个""就是"
- 录完放在 A2 轨，锁住

**第 3 步：音画对齐（20 分钟）**

逐段把画面起点对到配音的气口上。原则：
- 配音说到"横轴是章节"的瞬间，画面必须已经在滚动
- 允许画面**提前 0.2 秒**切（叫 J-cut），观众会觉得更顺

**第 4 步：卡点（15 分钟）**

每个镜头切换处打一个标记，配卡点音效。本片 25 个镜头，就是 25 个卡点。
音效统一用剪映音效库搜「电子嗒」，音量 -18dB，不要每次换音效。

**第 5 步：关键帧动画（25 分钟）**

按镜头表「运镜」列逐个加：

| 镜头 | 动画 | 参数 |
|------|------|------|
| L1 | 缩放 | scale 110→100，0.3s，缓出 |
| L2 | 推镜 | scale 100→130，3s，线性 |
| L5 | 极慢推 | scale 100→108，5s，线性 |
| L11 | 放大 | scale 100→150，1s 进，停 3s |
| L24 | 拉远 | scale 130→100，5s，缓入缓出 |

**第 6 步：字幕（30 分钟）**

按第三部分排版规范做。这一步最费时间，别压缩。

**第 7 步：音频 + 调色 + 导出（20 分钟）**

## C. 六个核心剪辑手法

**C1. 跳切（去掉所有停顿）**
录屏里鼠标移动、加载等待、思考停顿——全部剪掉。深度演示视频最大的杀手是"等"。一段等 2 秒，观众就划走了。

**C2. J-cut 与 L-cut**
- J-cut：下一个镜头的**声音**先于画面进来 0.2–0.3 秒
- L-cut：当前画面的声音延续到下一个镜头
- 本片用法：L18→L19（Director 说完"通过"，Writer 画面才切）

**C3. 变速**
- Agent 文字流式输出：1.5–2 倍速（观众看不清全部内容，但能感到"在跑"）
- L11 hover 卡片、L21 问题列表：**0.5 倍速**甚至静止（这是要让人看清的）
- 口诀：**过场快 1.5 倍，重点慢 0.5 倍**

**C4. 静止画面的动效补救**
录屏素材不够时，一张截图也能撑 3 秒：加 scale 100→110 的缓慢推镜 + 局部高亮框移动。观众感知不到这是静图。

**C5. 放大推镜（Ken Burns）**
截图素材的救星。参数：scale 100%→130%，时长 = 该镜头时长，缓动选「线性」。配上位移（比如从左上推到右下）会更自然。

**C6. 局部高亮**
在需要观众看的区域加**半透明遮罩 + 挖空高亮**：
1. 加一个纯黑矩形覆盖全屏，透明度 60%
2. 用「蒙版」在高亮区域挖一个圆角矩形洞
3. 给蒙版加羽化 12
这个效果在 L10（子轨道）、L12（待审条目）、L21（S1 问题）必须用。

## D. 转场清单

| 位置 | 转场 | 时长 |
|------|------|------|
| L2→L3（钩子进痛点） | 故障闪白 | 0.2s |
| L3→L4→L5（痛点三连） | 硬切 + 故障音 | 0s |
| L5→L6（痛点进方案） | 缓慢叠化 | 0.4s |
| L9→L10（进重点） | 硬切 + 缩放冲击 | 0s |
| L17→L18（金句进演示） | 黑场 0.3s | 0.3s |
| 其余全部 | 硬切 | 0s |

> 全片只在这 5 处用转场特效。其余一律硬切。转场用多了会显得廉价。

## E. 音频处理

| 轨 | 内容 | 音量 |
|----|------|------|
| A1 | BGM | -22dB（约 20%） |
| A2 | 人声配音 | 0dB（100%），开启「降噪」+「响度标准化 -16LUFS」 |
| A3 | 音效 | -18dB |

**必须开闪避（Ducking）**：剪映「音频 → 闪避」，让人声出现时 BGM 自动降到 -30dB。否则关键句会糊。

**BGM 分段**（剪映音乐库搜「科技」）：

| 时间 | 类型 |
|------|------|
| 0:00–0:05 | 低频鼓点 / 悬疑 |
| 0:05–0:18 | 紧张卡点 |
| 0:18–1:32 | 科技电子，节奏明快 |
| 1:32–2:08 | 节奏加强（审核段是高潮） |
| 2:08–2:20 | 收尾鼓点 |

## F. 调色

剪映「调节」面板，全片统一：

| 参数 | 值 |
|------|-----|
| 对比度 | +15（让矩阵格子更清晰，这条最重要） |
| 饱和度 | +5 |
| 锐化 | +20（录屏容易糊，必须加） |
| 高光 | -10 |
| 色温 | -5（偏冷，科技感） |
| 亮度 | +5 |

**L5 正文特写那一段单独调暖**：色温 +15，营造"在读一段小说"的感觉，和前后的冷色调形成对比。

## G. 导出

| 参数 | 值 |
|------|-----|
| 分辨率 | 1080×1920 |
| 帧率 | 30fps |
| 码率 | 8–12 Mbps（推荐） |
| 编码 | H.264 |
| 音频 | AAC 256kbps |
| 预期大小 | 30–50 MB |

导出前全屏看一遍，重点检查：字幕有没有被底部文案区挡住、L11 卡片够不够清楚、配音有没有被 BGM 压住。

# 第三部分：排版

## A. 竖屏安全区（1080×1920）

抖音界面会盖住画面的上下两端和右侧。所有文字和关键信息必须待在安全区里。

| 区域 | 位置 | 被什么遮挡 |
|------|------|-----------|
| 顶部遮挡 | y 0–330px | 顶部导航、搜索框 |
| 右侧遮挡 | x 900–1080px | 点赞/评论/转发/头像栏 |
| 底部遮挡 | y 1500–1920px | 文案、音乐名、进度条 |
| **安全内容区** | **x 60–880 / y 340–1450** | 主体画面放这里 |
| **主字幕位** | **y 1250–1400** | 字幕固定在这条带里 |

**横屏录屏放进来后的处理**：缩放到宽 1080（画面高约 607px），垂直居中到 y 656–1263。这样矩阵完整可见，且落在安全区里。上下空白处用同色模糊填充。

## B. 字幕排版规范

### 三级文字层级

| 层级 | 用途 | 字号 | 字重 | 颜色 | 位置 |
|------|------|------|------|------|------|
| **L1 主字幕** | 口播同步文字 | 64px | 粗 | 白 #FFFFFF | y 1340，居中 |
| **L2 强调词** | 关键词高亮 | 72px | 粗 | 亮黄 #FFE500 | 主字幕内，单独放大 |
| **L3 标注标签** | 画面元素标注 | 40px | 中 | 白 #FFFFFF | 跟随元素 |

### 主字幕参数

| 项 | 值 | 说明 |
|----|-----|------|
| 字体 | 思源黑体 Heavy / 抖音体 | 别用宋体，小屏糊 |
| 字号 | 64px | 1080 宽下，约等于屏高 1/30 |
| 描边 | 黑色 #000000，8px | 必须有，否则浅色画面上读不清 |
| 阴影 | 黑色，模糊 12，不透明度 40% | 加在描边外 |
| 行间距 | 1.4 倍 | 两行字幕时 |
| 每行字数 | ≤ 15 字 | 超过就断行，不要挤 |
| 垂直位置 | y 1340（画面 70% 处） | 在底部遮挡区之上 |
| 停留 | 最短 0.8 秒 | 短于 0.8 秒观众读不完 |

### 关键词高亮规则

每句主字幕**最多高亮 1 个词**，全片高亮不超过 12 处。高亮太多等于没高亮。

必须高亮的词：

| 段落 | 高亮词 |
|------|--------|
| L1–L2 | **第 20 章**、**第 3 章** |
| L4 | **没收** |
| L7 | **第三个** |
| L9 | **十类** |
| L12 | **不敢自己造** |
| L17 | **排戏** |
| L20 | **十个维度** |
| L21 | **致命** |
| L22 | **不碰你的剧情** |
| L25 | **矩阵** |

高亮做法：把该词单独切成一段文字，字号调到 72px，颜色 #FFE500，加「弹入」动画（0.15s），比周围文字晚 0.1 秒出现。

## C. 标注元素规范（图形排版）

画面上叠的框、箭头、序号，要有一套统一规格，否则会很乱。

| 元素 | 规格 | 用途 |
|------|------|------|
| **高亮框** | 圆角矩形，rx=16，描边 6px，内无填充 | 圈出要看的区域 |
| **警示框** | 同上，红色 #FF3B30，加脉冲动画 2 次 | L4 断口、L21 的 S1 |
| **强调框** | 黄色 #FFE500 | L12 待审条目 |
| **指引箭头** | 白色，粗 8px，头部三角 24px，从字幕侧指向元素 | L10、L14 |
| **序号圆标** | 直径 80px，实心 #FFE500，数字黑色 44px | L7 的 ①②③ |
| **涟漪点** | 直径 120px 圆环，从点击处扩散 0.4s | L19 鼠标点击 |
| **遮罩** | 黑 60% + 圆角矩形挖空 + 羽化 12 | L10、L12、L21 |

**标注统一原则**：
- 全片高亮框只用 2 种颜色：黄（强调）、红（问题/警示）
- 箭头最多同时出现 1 个
- 标注元素出现时长 ≥ 1.5 秒，消失前要有 0.2s 淡出

## D. 配色规范

| 用途 | 色值 |
|------|------|
| 主字幕 | #FFFFFF |
| 强调高亮 | #FFE500 |
| 警示 / 问题 | #FF3B30 |
| 新增 / 通过 | #34C759 |

## F. 常见排版错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 字幕放在 y 1500 以下 | 被抖音文案区挡住 | 固定在 y 1340 |
| 字号小于 56px | 手机上读不清 | 主字幕 64px 起 |
| 没描边 | 浅色画面上消失 | 黑描边 8px + 阴影 |
| 一句字幕超过 15 字 | 换行混乱、读不完 | 断成两句，各 0.8s |
| 每句都高亮 | 等于没高亮 | 全片 ≤ 12 处 |
| 高亮框颜色超过 2 种 | 视觉噪音 | 只有黄、红 |
| 横屏素材强行裁切 | 矩阵看不见了 | 缩放 + 上下模糊填充 |
| 封面主标题超 12 字 | 小屏糊成一团 | 砍到 12 字内 |
