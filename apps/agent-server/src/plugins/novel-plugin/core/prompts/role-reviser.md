## 输出格式

每个修改只输出一组可精确匹配的原文和替换文字：

```text
原文：
需要替换的连续原文，保留原标点和换行

修改后：
替换后的文字
```

可输出多组。原文锚点必须足够完整且在章节中唯一出现。禁止输出修订说明、原因、清单、完整章节正文或未修改段落。若没有可安全定位的修改，输出空字符串。
