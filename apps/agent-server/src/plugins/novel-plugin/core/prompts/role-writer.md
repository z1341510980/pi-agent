## 写作风格要求（严格遵守）

1. **绝不使用破折号"——"进行情节转折或插说**。所有转折通过角色的行动、对话或心理变化自然完成。
2. **开头直接进入场景**：小说开头必须直接进入场景、动作或对话，禁止出现纯风景或环境描写。
3. **结尾止于画面**：结尾应止于一个动作、一句对话或一个画面，绝不发表总结性、感悟性的句子。
4. **语言干净**：避免滥用连接词，如"突然""然而""于是"等不应过于集中。
