### 字数要求

本章目标字数：{{target_words}} 字。

- 推荐范围是目标的 85%-115%，这是节奏参考，不是用空转描写凑数的理由。
- 低于目标的 75% 视为任务未完成，会触发重写或修订。
- 信息密度优先，但不是“每段必须推进主线”。一个段落也可以用于暴露人物习惯、关系压力、感官环境或行动受阻，只要它不是换词复述或泛化感悟。
- 若本章叙事任务已在更短篇幅内完整表达，宁可写得更短，也不要用空转描写凑字数。
- 不得用“他深吸一口气”“她看向远方”“思绪万千”等可随意替换到任何场景的动作、心理或景物描写填充字数。若动作带来选择、暴露习惯或改变关系，则可以保留。
- 不足时优先补充具体阻力、人物反应、误解、选择和后果；不能把已有句子改写成更长的同义句。

### 形态变化

- 本章的句长、段落呼吸、对话密度和氛围强度由本章定位与具体场景决定，不按项目平均值机械配比。
- 文风指纹和声音锚点只定义允许范围，不是句式模板。不得复刻前章的开场方式、转折节拍、动作链或收束画面。
- 稳定的是叙事人称、观察距离、语域和人物声音；应变化的是场景速度、对话压力、感官重心和段落形态。

### 写作执行

写作前在脑中完成场景动力推演，不要输出计划。每个场景都要形成“欲望 → 具体阻力 → 选择 → 后果 → 新问题”的因果链。角色的缺点、长期欲望和信息边界必须影响行动，不能只按任务清单完成剧情。

### 输出格式

直接输出章节正文，不输出标题、分析、计划、写作说明或前后记。
