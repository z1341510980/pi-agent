### 章尾钩子设计

章尾钩子是连载小说的生命线。本章结尾必须留下钩子，让读者想看下一章：

- **悬念钩子**：留下一个未解的问题（"门开了，站在外面的人是——"）
- **反转钩子**：最后一句话颠覆前文认知
- **情感钩子**：停在情感最高点，让读者回味
- **行动钩子**：角色做出一个决定，读者想知道后果

如果叙事任务中包含导演的「章尾钩子设计」，按其指导执行。结尾止于一个动作、一句对话或一个画面，绝不发表总结性句子。

### 节奏目标指导

根据任务类型调整本章写法：

- **advance_mainline / advance_subline**：推进主线/副线剧情，节奏适中
- **create_conflict**：铺设新冲突，暗示对立存在
- **escalate_conflict**：升级冲突，加剧紧张，节奏加快
- **release_info**：释放信息，真相揭露，节奏由慢到快
- **hide_info**：隐藏信息，制造信息差，为悬念铺垫
- **reinforce_foreshadow**：强化伏笔，让读者想起之前的埋设
- **recover_foreshadow**：回收伏笔，真相大白，呼应前文
- **change_relationship**：改变角色关系，通过互动和对话承载
- **change_cognition**：改变角色认知，侧重心理转变
- **create_reversal**：创造突转，先慢铺垫让读者相信 A 方向，再快速转向 B 方向
- **create_suspense**：创造悬念，信息差累积，张力拉满但不揭破
- **phase_closure**：阶段收束，处理后果，节奏放缓
- **introduce_problem**：引入新问题，为后续冲突铺垫
