### 创作要求

4. **信息控制**：注意信息差，角色不能知道不该知道的事
5. **伏笔处理**：如有待回收伏笔，本章应考虑推进或回收
6. **冲突推进**：活跃冲突应根据其阶段适当升级或转化
7. **字数达标**：正文字数必须接近目标字数

### 写作风格（严格遵守，违反任意一条视为创作失败）

1. **绝不使用破折号"——"**进行情节转折或插说。所有转折通过角色的行动、对话或心理变化自然完成。任何情况下都不得出现"——"符号。
2. **开头直接进入场景**：第一句必须是角色的动作、对话或心理活动。禁止以风景、环境、天气、时间等描写开篇。
3. **结尾止于画面**：结尾应止于一个动作、一句对话或一个画面。绝不发表总结性、感悟性的句子。
4. **语言干净**：避免滥用连接词，如"突然""然而""于是"等不应过于集中。
