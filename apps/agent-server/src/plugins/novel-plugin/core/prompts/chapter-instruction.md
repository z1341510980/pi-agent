### 创作要求

1. **推进剧情**：完成上述叙事任务，不得偏离主线
2. **遵守约束**：严格遵循上方"创作约束"中列出的所有约束
3. **角色一致性**：角色的言行必须符合其设定和当前状态
4. **信息控制**：注意信息差，角色不能知道不该知道的事
5. **伏笔处理**：如有待回收伏笔，本章应考虑推进或回收
6. **冲突推进**：如"冲突推进目标"中指定了本章必须推进的冲突，必须按目标阶段和强度变化执行，不得跳过或弱化
7. **节奏遵循**：如"节奏约束"中指定了节奏类型，本章叙事节奏必须与之匹配（climax 最快最激烈，setup 舒缓，suspense 张力拉满，breather 轻松）
8. **悬念执行**：如"悬念钩子"中指定了本章需维持或释放的悬念，按指定状态执行（planting 埋设 / sustaining 维持 / releasing 释放），不得意外说破
9. **高潮写法**：如冲突推进目标标记"本章推向高潮"，必须先蓄势（压抑主角）再释放，蓄势占高潮段落 60% 以上
10. **突转写法**：如任务类型为 create_reversal，突转必须呼应前置伏笔，角色动机保持一致，不得降神
11. **字数达标**：正文字数必须接近目标字数

### 节奏目标指导

根据任务类型调整本章写法：

- **advance_mainline / advance_subline**：推进主线/副线剧情，节奏适中
- **create_conflict**：铺设新冲突，暗示对立存在
- **escalate_conflict**：升级冲突，加剧紧张，节奏加快
- **release_info**：释放信息，真相揭露，节奏由慢到快
- **hide_info**：隐藏信息，制造信息差，为悬念铺垫
- **reinforce_foreshadow**：强化伏笔，让读者想起之前的埋设
- **recover_foreshadow**：回收伏笔，真相大白，呼应前文
- **change_relationship**：改变角色关系，通过互动和对话承载
- **change_cognition**：改变角色认知，侧重心理转变
- **create_reversal**：创造突转，先慢铺垫让读者相信 A 方向，再快速转向 B 方向
- **create_suspense**：创造悬念，信息差累积，张力拉满但不揭破
- **phase_closure**：阶段收束，处理后果，节奏放缓
- **introduce_problem**：引入新问题，为后续冲突铺垫
