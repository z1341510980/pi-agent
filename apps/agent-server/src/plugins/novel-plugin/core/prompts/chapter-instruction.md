### 写作执行

写作前在脑中完成场景动力推演，不要输出计划。每个场景都要形成"欲望 → 具体阻力 → 选择 → 后果 → 新问题"的因果链。角色的缺点、长期欲望和信息边界必须影响行动，不能只按任务清单完成剧情。

### 形态与节奏目标（写作时控制，退回重构的判定线）

以下是与审稿门同口径的节奏底线，写每一段时就对照，而不是写完再补救：

- **连续单句短段不超过 2 段**。独立成段的超短句只留给真正改变局势的动作或台词；叙述请用"动作+感知+反应"撑出 2 行以上的呼吸。
- **18 字以内的超短段不超过全文段落的三成**。超过这个密度，正文会呈提纲式碎片节奏。
- **台词不要每句都以句号完整收尾**：加入被打断的半句、答非所问、没说完就转向。连续三句完整陈述句就该检查。
- 段落长度要有梯度：既有 3 行以上的长段，也有一两行的顿点，不要通篇一种节拍。

### 输出格式

直接输出章节正文，不输出标题、分析、计划、写作说明或前后记。
