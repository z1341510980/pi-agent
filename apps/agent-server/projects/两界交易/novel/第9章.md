# 第9章

叶明远走了不到二十步。

身后的脚步声就响起来了。不紧不慢，像踩着他的心跳节拍。

他没有回头，加快脚步又走了几步，然后听见身后传来一声咳嗽。

“行了，别跑了。”

赵岩的声音从矿道入口的方向飘过来，不高不低，带着点不耐烦。叶明远站住了。他没转身，但也没有再往前走。他能感觉到赵岩站在他身后大约七八步的位置，手里的火把将他的影子拉长，投在废弃巷道的碎石地面上。

“我说话你听见没有？”

叶明远转过身。

赵岩站在矿道入口的光影交界处，手里举着一根松脂火把，黑烟滚滚往上冒。他脸上的表情看不出喜怒，嘴角叼着那根铸铁烟杆，烟锅里的火星一明一灭。他没有往前走，就卡在入口处，像是刻意留出一条退路。

叶明远知道那不是给他留的。

“工头。”他开口了，声音比预想中平静，“有事？”

赵岩没接话。他把烟杆从嘴里取下来，在墙上磕了磕烟灰，火星溅在潮湿的石壁上，嘶的一声灭了。然后他抬头，上下打量了叶明远一眼，目光从他的脸移到他的衣襟内侧——玉佩的位置。

“你刚才，”赵岩说，“在运功。”

没有问号。是陈述句。

叶明远沉默了两秒。他在脑子里飞快地跑了几条分支：否认——赵岩已经感知到了灵气波动，否认没有意义；承认——但不知道赵岩的态度；转移话题——但已经被堵在废弃巷道里，没什么可转移的。

“是。”他说。

赵岩盯着他看了三秒，然后做了一个出乎叶明远意料的动作。他把火把插进墙上的裂缝里，蹲了下来，把烟杆叼回嘴里，像是准备长聊。

“练的什么功法？”他问。

“《引气诀》。”叶明远说。这是实话。在矿坑这种地方，低阶散修的入门功法无非就那么几种，瞒不住也无需瞒。

赵岩点了点头，吐出一口烟。“引气诀啊。”他拖长了音，“那玩意儿老子年轻时也练过，效率低得跟用勺子挖矿似的。你能练出动静来，倒是稀罕。”

他没有问叶明远从哪里搞到的功法，也没有问练了多久。他抽了两口烟，烟雾在火光中缓缓上升，然后被巷道里的穿堂风卷走。

“你刚才那一下，”赵岩说，“气息冲到了哪个位置？”

叶明远没有立刻回答。他在判断这是一个普通的问题还是某种试探。但转念一想，赵岩既然能感知到他的灵气波动，说明对修炼的感知力不弱，在这个距离上瞒也瞒不住。

“丹田。”他说，“气走了一个小周天，最后归入丹田的时候没压住，溢了一丝出去。”

赵岩的眼睛亮了一下。不是那种惊喜的亮，是那种确认了某个猜测之后的目光。

“小周天归丹田，”他重复了一遍，“你凝气了？”

“还没完全凝住。”叶明远说，“快了。”

快了。这是实话。优化过的《引气诀》把那条路缩短了大半，如果再给他两天时间，他有把握跨过那道门槛。但他没有说具体的时间——在这种对话里，留一点余地不是坏事。

赵岩盯着他看了好一会儿。烟杆在手指间转了一圈，他忽然笑了一下。不是那种阴险的笑，是那种路边捡到一块成色不错的矿石时，意外的、满意的笑。

“老子在这矿坑里干了八年，”他说，“见过不少杂役。有偷懒的，有耍滑的，有闷头干活的。偷偷修炼的也见过几个，但没有一个练出名堂来。这里的灵气太稀薄了，碎石里那点溢散出来的东西，够干什么？”

他顿了顿，把烟杆从嘴角取下来，指向叶明远。

“但你练出来了。”

叶明远没接话。他在等赵岩的下文。铺垫完了，该说正事了。

赵岩站起来，拍了拍裤腿上的灰。他没有往前走，仍然站在巷道入口的位置，但语气比刚才认真了一些。

“小子，你知道青池宗外门弟子的考核门槛是什么吗？”

叶明远知道。他在杂役坑这几个月，听矿工们聊过无数次。青池宗外门弟子的最低要求是：炼气期第一层圆满，能独立完成一个小周天的真气运转。他现在距离那个门槛已经非常近。

“炼气一层圆满。”他说。

“对。”赵岩点了点头，“你知道达到了这个门槛，意味着什么吗？”

叶明远知道。这意味着他从一个随时可以被替换的杂役，变成了有资格参加外门考核的候选人。但他没有回答，等着赵岩自己说出来。

赵岩又笑了一下。他把烟杆别回腰间，双手抱在胸前，靠着潮湿的矿道墙壁，姿态放松，但目光一点都没放松。

“老子可以推荐你。”

叶明远愣了一下。

“杂役坑的工头有一个推荐名额，”赵岩说，“每个季度可以推荐一个人直接参加外门考核，不用排队等半年后的统一招录。老子上个季度的名额没用，再不用就作废了。”

他说得很随意，像是顺口提了一件不起眼的小事。但叶明远注意到他说这些话的时候，目光一直没有离开自己的脸。

“条件呢？”叶明远问。

赵岩嘿了一声。“聪明。老子就喜欢跟聪明人说话。”

他从墙上取下火把，往巷道里走了两步，火光照亮了叶明远的脸。赵岩的表情在光影中显得有些晦暗不明，但他的语气是坦白的。

“条件只有一个：你进了青池宗之后，混得好不好都跟老子没关系。但万一有人问起来是谁推荐你的，你得说是工头赵岩。就这么简单。”

叶明远看着赵岩的眼睛，没有说话。

他理解了。赵岩不在意他有什么秘密，不在意他从哪里搞到的功法，不在意他怎么在灵气稀薄的矿坑里修炼的。赵岩只需要一个业绩——一个从他管辖的杂役坑里走出去的外门弟子。这在青池宗的考核体系中算工头的政绩，有实打实的奖励。

灵石奖励。

叶明远在矿坑里待了几个月，虽然没接触过上层信息，但这些底层规则他从矿工的闲聊中拼凑出了大概。工头每推荐一个合格的外门弟子，可以从宗门领到五十块下品灵石的奖励。对赵岩这种卡在炼气中期多年的外门弟子来说，五十块灵石是一笔不小的数目，够他买几枚增进修为的丹药，或者攒起来换一件像样的法器。

“就这个？”叶明远问。

赵岩笑了一声。“就这个。”

叶明远沉默了一会儿，然后说：“我知道了。谢谢工头。”

赵岩摆了摆手，脸上的表情松弛了几分。他转身往矿道入口走了两步，又停住了，没有回头。

“小子，”他对着墙上的火把说，“老子知道你身上有秘密。”

他的声音平淡，不带威胁，像是在陈述一个事实。

叶明远没有说话。

“你那把会响的铁家伙，”赵岩继续说，“还有你那些突然冒出来的力气和速度，跟你的修为不匹配。你不是在矿坑里才开始修炼的，对吧？你在来这之前就有些底子。”

他转过身来，火把的光把他的脸分成明暗两半。

“但老子不介意。”

他说这话的时候语气很平静，甚至带着点疲惫。像是把一道门推开了一条缝，又自己把它关上了。

“每个人都有自己的门道，”他说，“老子也有。你那个秘密，只要不把麻烦带进矿坑里，不牵连老子，你就自己留着。”

叶明远看着他，没有说话。

赵岩等了两秒，没等到回应，啧了一声。“别这副表情，老子不是要挟你。要挟你，刚才老子就带着矿卫来搜了。”他把火把举高了一点，“老子就是想告诉你——你的事情，老子不管。但你出去之后，记得是谁把你送出去的。”

他说完这句话，转身往外走。走了几步，又停住了。

“对了，”他头也没回，“你那个法宝，铁家伙，能在地上钻洞那个，挺有意思的。下次用的时候尽量别让人听见动静。”

叶明远的心跳漏了一拍。

赵岩没有等他回应，举着火把走进了主巷道。脚步声在矿道里回响，越来越远，最后被巷道拐角吞没。

叶明远站在原地，听着那串脚步声消失。

废弃巷道里只剩下他一个人。插在墙上的那根火把还在燃烧，油脂滋滋作响。他把手伸进衣襟内侧，摸到玉佩温凉的表面，感受着它贴在自己胸口的位置。

刚才那几分钟的对话，信息量很大。

第一，赵岩确实感知到了他的修炼波动，但态度不是追究，而是利用。赵岩需要一个推荐名额去换奖励，而他恰好需要一个推荐名额。这是一笔交易，双方各取所需。

第二，赵岩知道冲击钻的事。不只知道——他知道叶明远是用法宝完成定额的。但他选择不计较。理由跟第一条一样：叶明远完成定额，免去了他的麻烦；叶明远突破修炼，给了他推荐名额。两件事都不损害他的利益。

第三，也是最关键的一点：赵岩把话挑明了，但同时也把底线划清了——只要不把麻烦带进矿坑，他可以当作没看见。

叶明远在脑子里把这几层关系过了一遍，确认没有遗漏。然后他深呼吸了一口气，胸腔里的空气带着火把燃烧后的焦糊味和潮湿的石头味，这是他几个月来最熟悉的味道。

他抬脚，准备走出废弃巷道。

然后他停住了。

有一个问题。

从头到尾，赵岩问了他冲击钻的事，感知到了他的修炼波动，说了“不介意你的秘密”，给了他推荐名额，甚至提醒他下次注意噪音。

但有一个人，赵岩自始至终没有提过。

孙疤。

矿坑里少了一个人。孙疤的工位空了两天，管事那边登记了一笔“失踪”，但那是下层文书在做的例行记录。按流程，矿坑里出现非正常减员，工头需要签字确认。赵岩不可能不知道孙疤不见了。

但他没问。

不仅没问——他在整个对话中，没有任何一句话、一个眼神、一个停顿，指向这个空缺。

叶明远站在废弃巷道的入口处，火把在他身后燃烧，将他的影子拉长在碎石地面上。他的手指悬在半空中，然后慢慢放了下来。

有两种解释。

一种是赵岩真的没在意。矿坑里少个人太正常了，每个月都有死伤的，他懒得记每个人的名字。

另一种是赵岩在意，但故意不问。

叶明远把手放回身侧。他弯腰捡起地上的矿镐，走回采石面。矿镐砸在石壁上的声音在巷道里单调地回响着，一声接一声，像他自己的心跳。

他还没有想通。

但他知道，这件事不能就这么翻篇。
