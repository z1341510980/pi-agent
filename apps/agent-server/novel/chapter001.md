# 第1章

碎石砸在脚边，溅起的粉尘糊了满脸。

叶明远没躲。他弯下腰，把刚敲下来的石块捧起来，扔进身后的板车。板车已经装了大半车，但他扫了一眼计数柱上的刻度，心往下沉了沉。

还差三分之一。

监工刘麻子的声音从碎石场那头飘过来，隔着漫天粉尘依然刺耳：“今天的定额，太阳落山前完不成的，自己滚出大阵。潼关不留废人。”

周围没人吭声。十几个穿着灰扑扑道袍的汉子埋头干活，锤子砸在石头上的声音此起彼伏，单调得像一首丧歌。

叶明远舔了舔干裂的嘴唇，继续抡锤。

双手的血泡早就破了，掌心裹着一层粗布，血渗出来把布染成深褐色，干了又湿，湿了又干。三个月前刚被赶到碎石场的第一天，他疼得整夜睡不着。现在他已经学会忽略它——就像忽略胃里火烧火燎的饥饿感，忽略肺里灌满粉尘的灼痛，忽略那种从骨髓里往外渗的疲惫。

他把锤子举过头顶，砸下去。

碎石场在潼关城外西北角，紧挨着九州镇魔大阵的边缘。大阵的光幕就在几十丈外，白天看是一层淡蓝色的透明屏障，延伸到天边，望不到尽头。光幕之内是人族最后的庇护所，光幕之外是无边无际的妖魔领地。

据说三十年前魔渊裂世的时候，这光幕挡住了第一波妖魔的冲击。据说这些年全靠这座大阵，人族才没有彻底灭绝。

据说。

叶明远只知道一件事：如果今天太阳落山前凑不够石料定额，他就得滚出大阵，去跟那些“据说”存在的妖魔做邻居。

他把锤子砸得更狠了。

碎石场的石料是用来修补阵基的，每天要上缴的定额是按照人头算的，每个人每天必须完成一百斤。完成不了的，第二天就不用来了——不是放你走，是把你赶出大阵。被赶出去的人没有一个活着回来，这是潼关城人尽皆知的常识。

叶明远来了三个月，送走了十七个人。

锤子砸在石面上，震得虎口发麻。他停下来喘了口气，汗水顺着下巴滴落，在滚烫的石头上嘶一声蒸干。

余光扫到脚边一只麻雀。

麻雀半边翅膀塌着，歪倒在碎石堆里，胸脯急促起伏，乌黑的小眼睛里全是恐惧。大概是撞到阵基受了伤，掉进来的。

叶明远看了它三秒钟。

如果是三个月前的他，大概会停下来，看看能不能救。前世的职业习惯里有个不成文的规矩——遇到bug就得修，遇到问题就得解决。

但现在他没力气了。

那种累不只是身体上的。是每天醒来就知道今天要搬石头，明天也要搬石头，后天也是，直到哪天搬不完，被丢出大阵喂妖魔的累。是明知自己在等死，却连恐惧都麻木了的累。

他收回视线，继续抡锤。

胸口忽然传来一阵温热。

那热度很轻，贴着皮肤，像是有人把一枚硬币捂热了放在那里。叶明远手上的动作顿了一下，下意识摸了摸衣领下的玉佩。

玉佩跟了他半年了。

半年前他刚穿越到这个世界的时候，这玉佩就挂在他脖子上。他试过很多方法研究它：用灵力探过，用水泡过，用火烧过，甚至试着往里面注入灵气——都没反应。除了质地温润、雕工精细之外，它就是一块普通的玉石。

他唯一确定的是，这玉佩和他穿越有直接关系。因为穿越前他最后触碰的东西，就是它。

那天晚上他在出租屋里加班到凌晨三点，揉了揉眼睛，爬起来倒水。路过书桌的时候，手肘碰翻了桌上那块从潘家园淘来的老玉佩。他下意识伸手去接，指尖碰到玉佩的瞬间，眼前一黑。

然后就到了这里。

没有仪式，没有咒语，没有阵法。就是碰了一下，就穿了。

这个事实他一直觉得不合理。就像一段没有报错信息就直接崩溃的代码，问题一定出在某个他看不见的底层逻辑里。但他没有时间去深究，因为穿越后的第一件事就是活下来。

他凭着前世看过几本网络小说的模糊记忆，在青云宗入门考核中压线入选外门。然后他发现自己没有灵根——测试石在他手里完全没有反应的那种没有。宗门的修炼功法他练不了，因为所有功法都要求先引气入体，而没有灵根的人根本感应不到灵气。

但他没有放弃。他花了一个月时间，用最笨的方法——在宗门藏书阁里翻了三百多本杂书，在一本被标注为“此诀废”的呼吸法残篇中找到了一丝门路。那本残篇写得极其晦涩，注释里说它的运转逻辑“与天道相悖”，被历代修士判定为废物。

叶明远看了一遍就明白了。

不是它废，是写注释的人看不懂它。那根本不是什么呼吸法，那是一套类似于“协议栈”的东西——不是教你修炼，而是教你如何绕过灵根的短板，直接用精神力和灵气建立连接。就像没有显卡也能用CPU软渲染一样，效率低，但不依赖硬件。

他花了两个月，用这种笨办法硬生生炼出了一丝灵力。

炼气一层。有史以来第一个不需要灵根引气入体的修士。

虽然只是炼气一层，只是那一丝微薄到几乎可以忽略不计的灵力，但那是他自己写出来的“底层驱动”。

而现在，胸口那股温热越来越明显。

叶明远停下锤子，把玉佩掏出来。

阳光透过碎石场的粉尘落在玉佩上，他清楚看到——玉佩在发光。

不是反射阳光的那种亮，是从内部透出来的光，像是一颗微小的灯泡被点亮了。温润的青色玉石里，有一缕细若游丝的光芒在游走。

他愣了。

半年了，这东西头一次有反应。

监工刘麻子的声音又从远处传来：“那边那个，发什么呆！还想不想干了！”

叶明远把玉佩塞回衣领，重新抡起锤子。但他脑子里已经不在想石头的事了。

玉佩在发光。

这意味着什么？

他深吸一口气，一边机械地砸石头，一边分出一缕心神，催动体内那丝灵力，缓缓注入胸口。

这是他早就想过的测试方案。之前试过很多次，灵力注入玉佩就像水倒进沙漠，毫无反应。但现在玉佩自己亮了，说明有什么东西变了。

灵力顺着经脉流向胸口，触碰到玉佩的表面。

那一瞬间，叶明远感觉整个世界安静了一秒。

然后他听到了声音。

不是碎石场的锤声，不是监工的吆喝，不是风声。是一个完全陌生的、带着电流杂音的声音——

“……信号调试，测试一二三。喂？”

叶明远的锤子停在半空。

那个声音继续说：“哎，通了？喂？能听到吗？什么玩意儿，这个号码段是……”

是中文。标准的、带着北方口音的普通话。

叶明远几乎要笑出来。

他没有哭，没有喊救命，没有像那些穿越小说里的主角一样激动到语无伦次。他只是默默地放下锤子，蹲下身，假装在捡石头，然后对着玉佩说了一句话。

声音很轻，甚至带着一丝不确定。

“你好。”

对面安静了两秒。

“呃，你好？”那个声音犹豫了一下，“先生你好，这个号码是市公安局值班电话，请问你报警吗？还是……你从哪里拿到这个玉佩的？”

叶明远闭了闭眼睛。

冷静，他对自己说。第一印象很重要。你不能上来就说“我是穿越者”，对方会挂电话。你得给他能核实的东西。

“我叫叶明远，”他说，“三个月前被报失踪。我的身份证号是……”他报了一串数字，“户籍地址是南城区长青路锦绣花园12栋402。你可以查一下。”

对面又安静了几秒。

然后键盘声响起。

“……你说你三个月前被报失踪？”那个声音的语气变了，从漫不经心的应酬变成了带着警惕的认真，“先生，你怎么知道这些信息的？”

“因为那失踪案报的就是我。”叶明远说，“三个月前，准确说是九十七天前，我家人报的警。承办派出所是南城分局幸福路派出所，立案编号你查一下应该能对上。”

对面沉默的时间明显变长了。

叶明远听到电话那头传来压低声音的交谈：

“周队，你过来看一下。”

“什么事？”

“有个报警……情况很复杂。”

几秒钟后，一个更加沉稳的声音加入通话：“你好，我是刑侦大队周建国。刚才你说的话我听到了一部分。你说你三个月前失踪了？”

“对。”

“那你现在在哪里？”

叶明远沉默了片刻，抬头看了看碎石场灰暗的天空。远处光幕的边缘，有黑色的雾气在翻滚蠕动。

“我在的地方叫潼关，”他说，“潼关是九州镇魔大阵西北方向的一个节点。按照修真界的历法，这里应该是……”

他顿了顿，快速在脑子里换算了一下时间。

“我穿越到这里已经半年了。”

电话那头一片寂静。

叶明远能想象对面两个人的表情——震惊、怀疑、觉得遇到了疯子。他有大概三十秒的时间来挽回这个局面，否则对方就会判定为精神异常者挂断电话。

他快速开口：“我知道你很难相信。我先把能给你核查的信息说完。我失踪那天是六月十三号，晚上加班到凌晨三点，第二天公司发现我没去上班，打电话没人接，两天后我家人报的警。我前一份工作在明远科技，做后端开发，工号是……”

他报了一串信息，语速平稳，像是在念一份报告。

他的习惯就是这样——遇到问题先拆解，找出最优解，按计划执行。慌乱不会提高成功率，只会增加出错概率。

“……你给的前台座机应该还有人记得我，”他收尾，“你打过去问一下就行。”

电话那头有个人开始快步走动，应该是那个叫周建国的。

年轻的声音留在了线上：“先生……不，叶明远是吧？”

“对。”

“你说的这些信息，我们确实能查到。但是，”那个年轻的声音停顿了一下，“你刚才说你穿越了？你明白这个说法在法律意义上意味着什么吗？”

“意味着你们的认知框架里没有对应的分类。”叶明远说，“我知道。所以我不指望你相信，我只要求你查证。信息对得上，你再决定下一步。”

对面又沉默了几秒。

然后那个年轻的声音说：“你等一下。我正在查。”

键盘声再次响起。

叶明远蹲在碎石堆里，手指无意识地摩挲着玉佩表面。玉佩的温热透过指腹传上来，像是一条看不见的线，连着另一个世界。

他忽然觉得鼻子有点酸。

半年来，他以为这辈子都回不去了。

“先生，”年轻的声音忽然响起，语气明显变了，“你给的身份证号对应的户籍信息和你刚才说的一致。失踪案，我也查到了——幸福路派出所受理，失踪人姓名叶明远，登记日期六月十五号。”

叶明远嗯了一声，尽量让自己的声音保持平稳：“还有其他信息需要核实吗？你大可以一起查。”

“你这个时间点太精确了。”对方的声音里带着一种说不清的复杂情绪，“一般报假警的人不会把立案编号记得这么清楚……”

“所以呢？”

“所以我在想，”那人深吸了一口气，“你到底是谁？你现在在哪儿？你说的那个什么潼关……到底是什么地方？”

叶明远没有直接回答。

他把玉佩换了一只手握着，感觉到那丝灵力正在缓缓消耗。他大概还有十分钟的时间。

“我想跟你说明白，”他压低声音，“但我现在的处境不太乐观。”

“什么处境？”

“我今天得凑够一百斤石料，”叶明远抬头看了一眼远处的计数柱，“如果太阳落山前完不成，我会被赶出大阵。大阵外面有妖魔——具体是什么东西我不清楚，因为被赶出去的人没有一个活着回来过。”

“……你这是，被迫劳动？”

“可以这么理解。”

对面的人沉默了一会儿，然后叶明远听到那个年轻人快速转身，朝着另一个方向喊了一句：“周队，这个我得跟你汇报一下……”

脚步声远去了。

电话那头安静下来。

叶明远俯身捡起一块碎石，在手里掂了掂。他的目光不由自主地飘向光幕之外的远方。黑色雾气翻滚的地方，隐约能看到一些轮廓模糊的影子——那是妖魔的巢穴，还是某种巨型生物的骸骨，他分不清。

但今天之前，他从来没觉得这些东西和自己有直接关系。因为他知道自己总有一天会完不成定额，会被丢出去。那只是时间问题。

可现在不一样了。

他把玉佩攥在手心，感受那缕微弱的温度。

通道是开的。

对面的人虽然没有直接说信了，但他们在查——查他说的每一个字。只要信息对得上，他们就会开始动摇。而一旦动摇，事情就有转机。

脚步声回来了。

那个年轻的声音重新响起：“叶先生，你还在线吗？”

“在。”

“我把情况跟领导汇报了。”那人的声音变得正式了一些，“领导的意思是……你先别急，我们这边需要一点时间来核实你提供的信息。你刚才说的那个情况，关于你今天完不成定额就会被……那个，赶出大阵，这个时间点是今天日落？”

“对。”

“我们会尽快处理。”那人语速快了起来，“你那边注意安全，保持这个通讯畅通。我姓张，张恪。如果你那边信号断了——不是，我不知道这东西怎么形容——反正你尽量多打几次。”

叶明远嘴角动了动，算是笑了一下。

“好。”

他顿了顿，又说：“张恪警官，有一件事我要提前告诉你。”

“你说。”

“你手里拿着的那个玉佩——它是不是在发热？”

对面安静了。

过了好几秒，张恪的声音才重新响起，带着一种努力维持稳重却明显变了调的语气：“……你怎么知道？”

“因为我在用灵力驱动它。”叶明远说，“你可以检查一下，那个玉佩没有电池，没有电路板，没有任何电子元件。但它就是有温度。”

电话那头传来一阵急促的低语。

然后是一个更沉稳的声音——周建国的声音插了进来：“小张，把玉佩拿来我看看。”

窸窸窣窣的声音。

又是沉默。

然后周建国开口了，声音里那种经验丰富的沉稳第一次出现了一丝裂缝：“……确实没有电路。我和小张都检查了。”

“它在发光吗？”叶明远问。

“……对。”

“那就是我在占用通讯的意思。”

叶明远感觉到体内的灵力正在迅速消耗。他大概还有三到五分钟。

“我灵力快不够了，”他快速说，“就是驱动这个通讯的能量。我今天已经消耗了不少，剩下的撑不了太久。”

“你会怎么样？”张恪问。

“灵力耗尽的话，区别不大。”叶明远说，“就是玉佩会冷却下来，通讯会断开。但玉佩的通道还在，只要我恢复灵力，可以重新激活。”

他想了想，又补了一句：“所以你们最好快点核对信息。下次我打过来不一定是什么时候。”

“……好。”张恪的声音重新变得职业化，“我这边会尽快。你那边……你注意安全。”

叶明远嗯了一声。

他能感觉到灵力已经见底了，像是快要没油的引擎，开始断断续续地抖动。

“我要挂了，”他快速说，“下次打过来之前我会先攒够灵力。你们这边如果查到了什么……张恪警官，你自己判断该怎么处理。但有一条——这件事如果往上报，你最好挑一个脑子够用、接受能力强的人。”

“为什么？”

“因为，”叶明远说，“如果你们决定帮我，我需要的东西可能比你们想象的要复杂得多。”

通讯中断了。

玉佩的光缓缓黯淡下去，但叶明远感觉到它的触感依然残留着一丝温热。

他没有立刻站起来。

他蹲在碎石堆里，低着头，看着手心里的玉佩。指尖残留的温度很轻，但那温度带来的东西很重——那是半年来，他第一次在绝望之外感受到的东西。

他抬起头，看了一眼远处的计数柱。

还差三分之一。

太阳还挂在天上，但已经开始往西斜了。他不知道自己攒够灵力的速度有多快，不知道下次通讯什么时候能打出去，不知道蓝星那边的人会不会真的把他当一回事。

他不知道的事情太多了。

但有一件事他可以确定。

他站起来，重新抡起锤子。

砸下去的力道比之前重了三分。不是因为绝望，是因为他有了一个理由。

那个数字在脑子里跳动着，像是一个被重新启动的进程：

110。
