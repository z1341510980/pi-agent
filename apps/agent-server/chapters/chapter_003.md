# 第3章

叶明远握着玉佩靠在一块半人高的碎石后面，手指能感觉到玉佩在变温。从冰凉到温热，又从温热回冰凉，像一个在调试信号的对讲机。

太阳又向西沉了一截。

从玉佩沉寂到现在，至少过了半个时辰。蓝星那侧没有回音，没有声音，没有灵力反馈。他不知道对面是在商量方案、在调试设备，还是已经放弃了这条通道。

手里的碎石镐还在机械地挥着，但他刻意放慢了节奏。

理智告诉他应该趁还有时间继续按老办法采石，能多一块是一块。但直觉告诉他蓝星侧一定在做什么。他的穿越本身就是一场豪赌，眼下不过是另一场。

他把镐头往地上一杵，靠在矿壁上，余光扫过坑口。

落日余晖斜照进矿坑边缘，把每个人的影子拉得很长。七八个杂役还在争抢最后几块露头的石料。镐头砸击声、粗重的喘息声、偶尔一声咒骂交织在一起。空气里弥漫着石粉和汗水的味道。

一个瘦高的影子在坑口晃过一次。

赵岩。

工头今天巡视的频率比往常高。

叶明远把目光收回来，低头看着手里的玉佩。玉面微温，不高不低，像是电路板上的待机指示灯。这温度给了他一点安慰：通道没有彻底关闭。

然后玉佩猛地烫了一下。

不是温热，是烫。像是有人把烙铁贴在了掌心。

叶明远心脏猛跳了一拍，没有站起来，没有四下张望。他用余光扫了一圈周围，最近的矿工离他十几步远，都在低头干活。他慢慢站起身来，拖着镐头，假装要换一个采石位置，不动声色地退到了矿坑最深处、靠近废弃矿道的一个角落。

那里堆着半人高的碎石渣，刚好挡住了坑口的视线。

玉佩越来越烫。

他蹲下来，把它放在碎石堆上，右手握着，左手虚按。

一阵说不清道不明的空间扭曲感从掌心传来。不是眩晕，不是疼痛，而是一种"有什么东西正在穿过一个不该存在的缝隙"的本能感知。像是有人在你脑子里轻轻拨了一下琴弦。

三秒。

五秒。

一把电冲击钻掉在了碎石堆上。

一块备用电池紧跟着落下来，滚了两圈，停在他脚边。

叶明远愣住了。

他低头看看电钻。黄黑相间的外壳，枪式握把，钻头前端还带着出厂时的防锈油。蓝星工地上最常见的那种冲击钻，几百块钱一把，插电就能用。

他捡起来，在手心掂了掂分量。

嘴角抽搐了一下。

“……还真能传。”

他把电钻翻过来看了一眼铭牌。220V，但这不重要。蓝星侧既然能传过来，说明他们考虑过供电问题，大概率和电池方案绑定。

他说不出心里是什么感觉。不是激动，不是热泪盈眶。更像是一个你赌了最后一次，结果真的押中了。一种茫然的、不太真实的庆幸。

玉佩传来三声短促的温热脉冲。短。短。短。

像在问：收到了吗？

叶明远把玉佩握紧，调出体内那丝微薄的灵力，往里注入了一短一长。

收到。

他站起来，把电钻塞进破旧的道袍里。衣袍宽大，勉强能遮住轮廓。又把备用电池揣进怀里，从碎石堆后走了出来。

矿坑里一切如常。没人注意到那个角落里发生了什么。

但叶明远没有看到的是：电钻穿过空间的那一瞬间，矿坑内所有的镇魔石料表面同时浮现了一层极淡的纹路，像石子投入水面时荡开的涟漪，然后迅速消退。

坑口的赵岩停下了脚步。

他回头看了一眼矿坑深处，眯了眯眼睛，什么都没说。

叶明远选了一个靠近废弃矿道的采石位置。这里离坑口最远，三面被碎石堆和岩壁包围，形成了一个天然的隔音死角。

他把电钻从衣袍里抽出来，握紧把手，大拇指按住开关。

深吸一口气。

按下。

钻头尖啸着撞上镇魔石料。

声音比他预想的大得多，尖锐刺耳，像指甲刮黑板的高频版本。但他的心反而放下来一半：镇魔石料本身有吸音特性，矿物质结构会吸收中高频声波，传到坑口时应该已经衰减到不足以引起注意。

真正让他意外的是低频振动。

电钻的震动顺着矿壁传导，从手指传到手腕，从手腕传到肩膀。他能感觉到整面岩壁都在跟着共振，细微的、持续的嗡嗡声。

钻头在石面上咬出了一个圆孔，边缘光滑，深度约两指。

十五秒。

他拿起手边的镐头，试着沿着圆孔凿了一下，石料沿着钻孔整齐地裂开。

一块标准尺寸的镇魔石料掉在地上。

十五秒。一块。

手工镐需要至少一盏茶的工夫。

他没有停下来算账，只是机械地重复：对准位置，按下开关，钻，换位置，再钻，凿开，捡石头。

半个时辰后，他身边堆了大约三十块标准石料。

又半个时辰，石料堆到了膝盖高。

他停下来，抹了一把脸上的汗和石粉，看了一眼天色。太阳还有一竿高，他不仅补齐了今天的定额，还多采了大约明天一半的量。

他把电钻关了，塞回衣袍里。

低频振动顺着矿脉传导开去，在矿坑深处某个人迹罕至的废弃矿道里，一块半嵌在岩壁上的巨大镇魔石原矿，出现了一道细微的裂纹。

没有人发现。

废弃矿道的更深处，似乎有什么东西在极轻极轻地回响。

叶明远隐约听到了，但不确定那是什么。他把注意力拉回来，靠在一块平整的岩壁上，闭上眼睛。

这是他几个月来第一次不带着"明天就要死了"的恐惧休息。

他运行起那部《引气诀》。

青池宗发给杂役的入门功法，比大路货还大路货，总共只有三条经脉的运转路线，任何一个有灵根的人花一个下午就能学会。但就是这个简陋到几乎不配叫功法的东西，在今天，在他体内，产生了让他自己都无法忽视的效果。

也许是身体已经饿透了、渴透了、累到了极限。当真正的灵气开始按照固定路线运行时，每一丝从周围空气中被牵引过来的灵力都被每一个细胞贪婪地吸收。没有浪费，没有溢散，像干涸太久的河床迎来了第一场雨水。

也许是数月来他偷偷吸收碎石中溢散的灵气，经脉已经被反复冲刷过无数次。每一次都只有头发丝那么一丝，但架不住次数多、时间长。《引气诀》一运转，那些原本粗糙、堵塞、半通不通的经脉路线，像被水冲过无数遍的管道，畅通无阻。

他沿着第一条经脉走了一周天。

第二条。

第三条。

灵力在他体内从那一丝极微薄的程度，增长成了一小股。他没法精确量化，但粗略估计大概有今天的四五倍之多。

按正常杂役的标准，这相当于从即将饿死的边缘恢复到了炼气初期的下限。

他睁开眼。

落日已经贴到了天边。

坑口传来赵岩那带着烟嗓子的喊声："收工！交石料！"

叶明远站起来。他已经很久没有这样站起来不觉得眩晕了。腿不软，腰不酸，眼前没有冒金星。

这种"正常人的身体"的感觉让他恍惚了一下，然后他背着满满一筐石料向坑口走去。

杂役们在坑口排成一排，挨个把背篓里的石料倒进公用的石筐里。赵岩站在旁边，手里拿着账册，每倒一篓就低头记一笔。

轮到叶明远了。

他把背篓翻转过来，石料哗啦啦地倒进石筐。数量明显比别人多出一截，而且每块石料尺寸匀称，断面整齐。不是镐头砸出来的那种犬牙交错的断裂面，而是一种圆润的、光滑的切口。

赵岩数了一遍，又数了一遍。

多看了叶明远两眼。

没说什么，在账册上记了数。

叶明远转身往回走。

“你小子。”赵岩在背后开口了，声音不紧不慢，“今天的石料，品相不错。”

叶明远的心跳快了半拍，但没有回头，语气平淡：“运气好，碰上一块松的矿脉。”

赵岩笑了笑。

笑容没有到眼底。

“那明天继续运气好。”

他挥了挥手，叶明远加快脚步走了。

赵岩站在坑口，看着那个背影消失在暮色里，拿起腰间的铸铁烟杆，塞了一撮烟丝，点上火。

叶明远今天的状态不对。昨天还饿得眼冒绿光，腿软得走路都打晃。今天交石料的时候，背脊挺直了不少，脚步也稳了。那些石料上的凹痕是圆形的、光滑的，不是镐头砸出来的，镐头的尖角会留下V形的砸痕。

而且他交的超额石料，按规矩可以折算成明天的任务量。他没提这茬。

赵岩吸了一口烟，慢慢吐出来。

他叫住一个路过的杂役，低声说了两句话。那人点了点头，把镐头往地上一放，转身往窝棚区走去。

夜色彻底降临了。

潼关的夜晚没有月亮的时候，黑得像一块实心的铁。矿坑里彻底安静下来，只有风从废弃矿道灌进来的呜咽声。

叶明远的窝棚在最边缘，离其他杂役的窝棚隔着七八步的距离。他盘膝坐在草席上，掌心握着玉佩，尝试着将一丝灵力探进去。

玉佩亮了一下。

很快，对面传来回应。微弱但稳定的灵力反馈，像远距离的信号灯在闪烁。蓝星侧的人在尝试建立通讯。

叶明远深吸一口气，将意识沉入玉佩，开始用灵力震荡的频率发送信息。

安全。

谢谢。

明天需要更多电池。

一遍。两遍。三遍。

他没有收到文字上的回复，但灵力反馈的节奏变了。从均匀的脉冲变成了长短交替的编码。对面接收到了，而且在尝试回复。

窝棚外，一个黑影蹲在三十步远的阴影里，眼睛一眨不眨地盯着窝棚的方向。

窝棚里透出一点极其微弱的、不似油灯的光芒。那光芒不是稳定的黄红色，而是一种淡青色的、像萤火虫一样的亮光。一明一暗，一明一暗，像是在说什么。

黑影数着那亮光的节奏，默默记在心里，然后弓着身子退出了阴影，消失在夜色中。

赵岩在工头独间里，把铸铁烟杆在桌腿上磕了磕灰。

听着心腹压低声音说完窝棚里的异常情况，他沉默了两息，只说了一个字：

“查。”
