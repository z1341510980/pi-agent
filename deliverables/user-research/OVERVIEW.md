# 概览：pi-agent 前端用户研究分析与研究计划

> 完整报告：`deliverables/user-research/pi-agent-ux-research-2026-07-28.md`

## 一句话结论
工作区**没有任何一手用户研究数据**，当前决策建立在"假设驱动设计"之上；需以二次综合 + 一手混合方法研究补证据缺口。

## 交付物包含
1. **数据资产审计**：5 类二手证据逐条标注类型、置信度、局限。
2. **二次研究综合**：假设型人物画像（A 职业作者 / B 业余作者 / C IP 策划 / D 通用 Agent 用户——D 为研究盲区）、痛点地图（带置信度）、假设型用户旅程。
3. **科学一手研究计划**：5 个研究问题、混合方法（访谈 + 可用性测试 + 问卷 n≥200 + 行为埋点）、样本量理由、招募筛选、研究协议、分析计划。
4. **建议与度量**：高 / 中 / 长期优先级 + 成功指标。

## 三个关键发现
- 战略文档里"用户研究员"的产出溯源后是**市场推算 + 竞品差评挖掘**，属"需求伪验证"。
- 置信度最高的自有缺口（Team UI / Gate 内联 / runtime 区分）违背自身设计原则"可信"，属"已知正确"项，可立即修。
- **通用 Agent 平台用户（画像 D）完全无研究覆盖**，是最大盲区。
