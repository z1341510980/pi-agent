## TL;DR（执行摘要）

- 核心目标：打造面向中文网文作者与业余写作者的「AI 副驾」（人为主笔、AI 打杂），以「小说圣经 + 长文记忆」攻克人设一致性与长文连贯两大行业生死线。
- 关键决策：将「人设/世界观一致性管理」与「长文连贯与记忆」列为 P0 核心壁垒；以「作者主权（不拿作品训练、版权归作者、可导出）+ 内置原创度/去 AI 味自检」填补行业信任空白；对标 DeepSeek 低价走免费 + 轻订阅。
- 下一步：2026 Q3 先打 MVP（小说圣经 + 长文记忆），内测 ≥200 名作者验证 OOC 防护，再于 Q4 公测补齐合规护栏与润色。

## 1. 产品目标（来源：战略综合 / 瑞思·竞析·数析）

- **G1 设定一致性护城河**：把「小说圣经」+ 长文记忆打造成业界第一的人设 / 世界观一致性引擎，将 OOC 与逻辑矛盾降至最低，形成数据 + 体验壁垒（对应瑞思 P0、竞析普遍短板）。
- **G2 副驾心智与作者主权信任**：固化「人为主笔、AI 打杂」定位，以「不拿作品训练、版权归作者」+ 内置原创度 / 去 AI 味自检，填补行业信任空白（对应数析 60% 读者排斥、平台封禁障碍）。
- **G3 成本友好下的规模化采用**：对标 DeepSeek 低价，提供网文专属节奏把控，以 WAU、采纳率、留存牵引可持续增长（对应数析北极星组合）。

## 2. 用户故事（来源：瑞思）

- **US1 职业作者·保更急救**：作为日更 5000 字的签约作者，我希望 AI 在卡文时基于「小说圣经」续写符合人设的剧情，以便不断更且不崩人设。
- **US2 业余作者·低门槛起步**：作为业余写作者，我希望套用网文模板快速生成大纲与首章，以便零基础产出过原创检测的成稿。
- **US3 IP 策划·人设矩阵**：作为剧情策划编辑，我希望批量管理多角色关系矩阵并一键生成改编分镜，以便高效评估 IP 可改编性。
- **US4 全体·去 AI 味**：作为任何作者，我希望润色后自动给出「AI 味 / 原创度」评分与修改建议，以便规避平台限流风险。

## 3. 用户研究洞察（来源：瑞思）

**三类核心用户**

- 职业 / 签约作者（约 50–100 万）：日更 4000–6000 字，诉求提效保更、卡文急救、润色。
- 兼职 / 业余作者（2000 万+，主体）：低门槛出框架、套模板、过原创检测。
- IP / 剧情策划编辑（数万级，付费意愿高）：故事结构、人设矩阵、改编分镜。

**最高频痛点**：人设一致性崩塌 OOC（约 90% 踩雷）、长文记忆衰减（1.4 万字后细节丢失）、设定 / 逻辑矛盾、AI 味同质化、平台封禁风险（16 家平台反洗稿公约）、版权不明、学习与费用门槛。第三方评测（如彩云小梦等）集中吐槽「长文逻辑崩 + 人设漂移 + 免费额度紧」，佐证一致性 / 长文记忆是真实高频痛点而非伪需求。

**需求优先级**：人设 / 世界观一致性 P0、长文连贯 P0、节奏把控 P1、灵感 / 卡文 P1、润色去 AI 味 P1、风格模仿 P2。

**关键启示**：定位「副驾」非「代笔」；小说圣经与长文记忆为核心壁垒；网文专属节奏；成本友好；内置合规护栏与训练数据授权透明 / 作者可退出训练承诺。

## 4. 竞品对比（来源：竞析，7 款）

| 产品 | 定位 / 模型 | 强项 | 弱项 | 价格 |
|---|---|---|---|---|
| 彩云小梦 | 国内最早续写 / 云锦天章 | 中文网文适配、角色语音 | 长文逻辑崩、人设漂移 | ¥25/月 |
| NovelAI | Erato (Llama3 70B) | Lorebook 设强、隐私加密 | 中文翻译腔 | $10–25/月 |
| Sudowrite | 专为小说 | Story Bible 长一致、润色风格强 | 长文仍需人工、贵 | $10–44/月 |
| 火山写作 | 字节豆包 | 免费、润色自然 | 续写不稳、限千字 | 免费 |
| 番茄 AI 助手 | 平台内置 | 免费、效率认可 | 训练争议信任危机 | 免费 |
| 笔灵 AI | 通用含小说 | 大纲 / 角色设定模块 | 小说深度一般 | ¥30–69/月 |
| Character.AI | 角色扮演 | 娱乐向、20M+ MAU | 非严肃写作 | 免费 / 订阅 |

**结论**：海外强设定 / 风格但中文弱；国内通用不专，长文一致性与设定管理是普遍短板；「作者主权」是信任空白——本产品差异化机会。番茄 2024-07「作品用于 AI 训练」引发作者联合抵制（"把作品当养料"），凸显中文作者对作品主权的强敏感，是「作者主权」定位最直接的情绪锚点与信任分水岭。

## 5. 数据依据（来源：数析）

- **市场**：全球 AI 写作辅助 2024 $23 亿 → 2030 $83 亿（CAGR 24.3%）；中国 AIGC 2024 436 亿 → 2030 1.14 万亿；网文营收 495.5 亿（+29.4%），作者 3119.8 万，IP 改编 2985.6 亿（约阅读 7 倍）。
- **采用**：阅文披露 75% 作家常态化用 AI；中国生成式 AI 用户 6.02 亿（普及率 42.8%）。
- **障碍**：平台封禁、读者约 60% 排斥 AI 文、质量 / 版权不确定。
- **北极星组合（上线 3 月）**：周活作家 WAU ≥5000、AI 内容采纳率 ≥60%、7 日留存 ≥20%；辅助：次留 ≥40%、单章生成 <30 秒、续写 + 润色渗透 ≥50%、免费→付费转化 ≥10%、NPS ≥30。

## 6. 需求池（来源：瑞思优先级 + 竞析差距）

| 编号 | 需求 | 优先级 | 验收标准 | 估算工作量 |
|---|---|---|---|---|
| R1 | 小说圣经（角色 / 世界观 / 关系管理） | P0 | 给定设定库，续写时人设偏离自动告警；支持导入 / 导出结构化设定 (JSON) | 大 |
| R2 | 长文连贯与记忆（长上下文 + 情节检索） | P0 | 1.4 万字后关键设定召回率 ≥90%；章节间矛盾检测可用 | 大 |
| R3 | 合规护栏与作者主权 | P0 | 明示不训练承诺；原创度 / AI 味自检评分并给修改建议 | 中 |
| R4 | 网文节奏把控 | P1 | 按章给出节奏（爽点 / 铺垫）建议；支持类型模板 | 中 |
| R5 | 卡文急救 / 灵感激发 | P1 | 输入断点生成 ≥3 条走向；可一键采纳 | 小 |
| R6 | 润色改写去 AI 味 | P1 | 润色后 AI 味评分下降且保留作者风格 | 中 |
| R7 | 风格模仿 | P2 | 上传样例提取风格向量并复用 | 中 |

## 7. 关键流程图 / UI 设计稿（来源：析客）

**核心流程（写作副驾）**

```mermaid
graph LR
A[导入/新建小说圣经] --> B[规划大纲/分镜]
B --> C[逐章写作]
C --> D{卡文?}
D -- 是 --> E[AI基于圣经续写/急救]
D -- 否 --> F[润色去AI味]
E --> F
F --> G[原创度自检]
G --> H[导出/发布]
```

**「小说圣经」管理面板（关键界面，ASCII）**

```
┌─ 小说圣经：<书名> ─────────────┐
│ [角色] [世界观] [关系图] [时间线] │
│────────────────────────────────│
│ 角色卡：姓名/年龄/性格标签/口头禅│
│ ⚠ OOC风险：本章对话偏离设定      │
│ 世界观：势力/法则/地图          │
│ 关系图：A—敌对→B；C—师徒→A    │
│ [+新增] [导入设定] [导出JSON]   │
└────────────────────────────────┘
```

面板实时联动写作区，人设偏离即时红点告警；设定可被续写 / 润色引擎实时调用。

## 8. Non-goals（来源：析客）

- 不做「AI 代笔 / 全自动成书」——坚持人为主笔。
- 不抓取或用用户作品训练模型（作者主权承诺）。
- 不做通用写作（论文 / 公文 / 营销），聚焦中文网文。
- v1 不内置付费阅读 / 分发社区（不做平台化）。
- v1 不做多语言出海（仅中文）。
- v1 不做 3D / 插画等美术生成能力。

## 9. 时间线 & 里程碑（来源：析客，对齐路径路线图）

- **2026 Q3 MVP**：R1 + R2 核心——小说圣经 + 长文记忆，内测 500 名作者验证 OOC 防护。
- **2026 Q4 公测**：加 R3 合规护栏、R6 润色，开免费层，冲 WAU 5000 与采纳率 60%。
- **2027 Q1 增长**：加 R4 节奏把控、R5 卡文急救，免费→付费转化 ≥10%，7 日留存 ≥20%。
- **2027 Q2 商业**：加 R7 风格模仿，NPS ≥30，确立中文网文副驾第一心智。

## 10. 待确认问题（来源：析客）

1. 长文记忆采用「全文重喂 + 向量检索」还是自研记忆压缩？影响成本与 R2 召回率。
2. 模型自研还是接入 DeepSeek / 豆包等低价 API？版权与成本如何平衡？
3. 原创度 / AI 味检测用第三方还是自研？与 16 家平台标准是否对齐？
4. 免费层额度与付费锚点如何设定，避免侵蚀业余作者主体盘？
5. IP 策划编辑的高付费场景，是否 v1 即纳入还是放到 v2？

## 待确认 / 假设 / Non-goals

- **假设**：本产品为 greenfield，市场规模多为估算或相邻赛道推算；竞析 / 瑞思提供的部分原文链接来自联网检索且未逐一核实，报告中仅作定性引用，不视为已验证可访问来源。
