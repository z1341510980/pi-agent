# 小说AI生成工具 竞品分析报告

**日期**：2026-07-22
**类型**：竞品分析
**参与成员**：竞析（竞品分析师，主笔）、瑞思（用户研究员）、数析（数据分析师）

---

## TL;DR（执行摘要）

- 核心目标：厘清小说 AI 生成赛道格局，为我方 0→1 产品定位寻找可防守的差异化切口。
- 关键决策：以「作者主权 + 中文网文垂直深耕 + 设定管理体系化」对抗字节免费生态与彩云先发优势，避开与通用写作工具的同质化竞争。
- 下一步：优先用 MVP 验证「小说圣经 / 长文一致性」壁垒假设（P0），并第一时间锁定「不拿用户作品训练」承诺建立信任护城河。

## 1. 竞品全景图（来源：竞析）

**A. 专业小说 AI 生成**
- **彩云小梦（彩云科技，国内）**：国内最早专注小说续写的 AI 平台。自研 DCFormer 架构 +「云锦天章」大模型，2024-11 V3.5 将上下文从 2000 字提升至 10000 字、续写连贯性提升 20%。功能含多风格续写、平行世界 / 世界观设定、角色语音互动（月 400 分钟免费）、改写扩写。会员 25 元 / 月或 188 元 / 年，免费版有额度限制。
- **NovelAI（美国 Anlatan）**：AI 故事讲述者 + 动漫图像生成。文本端 Erato 模型（2024-09，基于 Llama 3 70B 微调），图像端 NovelAI Diffusion V4.5。强项 Lorebook 设定管理、8192 tokens 上下文、加密存储。订阅 $10/$15/$25 每月，注册赠有限试用。
- **Sudowrite（美国，2020 成立）**：专为小说作者打造的 fiction AI。自研 Muse 模型 + 调用 Claude/GPT。核心 Story Bible（长篇一致性）、Draft 场景生成、Style Examples 文风模仿、AI Readers 模拟读者、Canvas 大纲模板。Hobby/Pro/Max $10/$22/$44 每月。

**B. 通用 AI 写作（含国内新锐）**
- **火山写作（字节跳动，国内）**：基于豆包大模型的免费中英文写作助手，主打润色 / 改写 / 续写 / 翻译 / 纠错。基础功能免费，部分来源称高级会员 ¥29/月起（口径不一，标注：暂无统一公开定价）。非小说专向。
- **笔灵 AI（国内）**：全能型 AI 写作（200+ 场景），小说模块含大纲助手、梗概、剧情创作、角色设定、续写 / 润色、百万素材库、风格迁移。免费版限次；会员约 29.9–69 元 / 月、年 299 元、终身 199–299 元（口径不一）。偏通用，小说深度一般。

**C. 网文平台内置 AI**
- **番茄小说 AI 助手（字节，国内）**：网文平台内置工具箱，含 AI 扩写 / 改写 / 续写 / 起名 / 自定义描写 / 卡文锦囊，2024-05 上线，免费（需同意 AI 条款）。2024-07 因「作品用于 AI 训练」引发作者联合抵制，后上线解除条款入口。

**D. Prompt 式角色扮演 / 对话 AI**
- **AI Dungeon（Latitude，美国，2019）**：文字冒险 / RPG 互动叙事平台。免费含广告，Premium $9.99–29.99/月。娱乐向，非严肃写作。
- **Character.AI（美国，2021）**：角色聊天 / 角色扮演平台，20M+ MAU（2024 中）。c.ai+ $9.99/月。未成年人安全为主要争议。

## 3. 市场数据 & 趋势（来源：竞析 + 数析）

- **全球**：AI 写作辅助软件市场 2024 年约 $23 亿 → 2030 年 $83 亿，CAGR 24.3%（Market Glass/GII，2025-08）。美国 2024 年 $5.94 亿；**中国**预计 CAGR 22.7%，2030 年达 $13 亿。
- **中国细分**：机构口径差异大——中研普华预测 2025 年文本生成器市场约 10 亿元；Spherical Insights 估算 2024 年 $47.5 万（口径 / 统计范围存疑）。**结论：暂无统一可靠共识数据**，整体处于高速增长早期。
- **网文下游**：网文营收 495.5 亿（+29.4%），作者 3119.8 万，IP 改编市场 2985.6 亿（约阅读 7 倍）；阅文披露 75% 作家常态化用 AI。
- **赛道动态**：阅文「妙笔」+ 作家助手；中文在线「中文逍遥」；七猫 × 文心一言；字节（火山免费 + 番茄内置 + 豆包）形成生态闭环。

## 4. 用户感知（来源：竞析 + 瑞思交叉印证）

- **彩云小梦**：好评「新手友好、解决卡文、脑洞好玩」；第三方评测集中槽点「套路化严重、长文逻辑易崩、角色人设随篇幅漂移、免费额度紧、付费性价比低」——佐证「长篇一致性 / 设定管理」是真实高频痛点而非伪需求。
- **NovelAI**：英文 / 二次元强、隐私好；中文「翻译腔」、有门槛、图像点数贵。
- **Sudowrite**：Story Bible 解决长篇一致性受专业作者认可；槽点「AI 腔、长文仍需人工把控」。
- **火山写作**：「中文润色自然、免费」；「长文续写不稳、全文限千字、审查严」。
- **番茄小说 AI**：效率认可，但**版权信任危机**是核心负面（"创作心血变 AI 养料"的 2024-07 训练争议），已成行业信任分水岭，凸显中文作者对「作品主权」的强敏感。
- **AI Dungeon / Character.AI**：娱乐性强；槽点集中在「AI 跑题、未成年安全 / 成瘾、幻觉」。

## 5. SWOT 分析（我方机会视角，来源：竞析）

- **S（可建优势）**：垂直定位中文网文 + 业余作者，海外工具中文弱、通用工具不专；五大能力闭环（长文连贯 + 设定管理 + 大纲分镜 + 润色 + 风格模仿）对标 Sudowrite Story Bible 与 NovelAI Lorebook。
- **W（劣势）**：未上线，无用户 / 品牌 / 数据；模型能力或依赖外部，与字节、彩云自研模型有差距；版权信任需从 0 建立。
- **O（机会）**：中文专业小说 AI 仍稀缺；番茄训练争议留下「作者主权」信任空白；长文一致性与设定管理是普遍短板；中文大神文风模仿需求未被满足。
- **T（威胁）**：字节生态（免费火山 + 番茄内置 + 豆包）可能降维碾压；彩云先发 + 中文优势；阅文妙笔 / 中文逍遥平台级玩家；通用大模型降价吞噬长尾功能；版权政策不确定。

## 6. 差异化机会（来源：竞析）

1. **立场差异化——「作者主权」**：明确「不将用户作品用于训练、版权归作者、可自由导出」，直击番茄争议痛点，建立信任护城河。
2. **中文网文垂直深耕**：提供网文体裁模板（玄幻 / 言情 / 悬疑 / 科幻）、爽点节奏、章末钩子、毒点检测等通用工具不具备的网文专属能力。
3. **设定管理体系化**：融合 Lorebook + Story Bible，做「角色卡 + 世界观 + 时间线 + 大纲分镜」联动，攻克长文一致性（彩云 / 火山最大短板）。
4. **风格模仿平民化**：中文大神文风模仿，低门槛对标 Sudowrite Style Examples，填补中文空白。
5. **免费 + 轻订阅获客**：提供可观免费额度（续写 / 大纲）建立口碑，避免番茄式霸王条款。
6. **社区化护城河**：做设定 / 角色卡分享，形成 UGC 壁垒；同步落实内容合规标识与数据加密（学 NovelAI XSalsa20）。

## 7. 行动建议（来源：竞析）

- 立项即公示「不训练承诺 + 作者可退出训练 + 版权归作者」，把信任做成显性卖点。
- MVP 单点突破「小说圣经 / 长文一致性」，用内测数据证明壁垒成立后再扩展。
- 节奏把控、毒点检测等网文专属能力作为与通用工具区隔的「尖刀功能」。
- 定价走「免费额度 + 轻订阅」，用成本友好覆盖 2000 万 + 业余作者长尾。
