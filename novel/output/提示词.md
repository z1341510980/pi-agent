# 《两界摆渡人》创作提示词（已确认定稿）

> 题材方向：穿越异界（修仙）+ 上交给国家（系统流 / 国家流爽文）
> 生成时间：2026-08-04
> 状态：✅ 已确认（用户选定：主角=大学生 / 异界=修仙 / 机构名保留 / 篇幅=长篇）

---

## 1. 题材定位

**类型**：都市现实为主舞台 + 异界修仙探险为资源来源 + 系统流 + 国家流（灵材/功法/丹方上交国家）。
**核心卖点**：主角不称霸异界，第一反应是"这玩意上交国家能换编制"。靠把异界资源搬回现实、反哺国家，实现"个人封神 + 国家崛起"双线爽感。
**基调**：现代、硬核、热血、带点黑色幽默；爱国但不说教，科学思维与修仙逻辑碰撞。
**对标感**：类似"异界物资上交国家 / 国械灵能混编"流，但主角身份为穷学生，主打"理工脑用异界资源降维打击"。

## 2. 世界观设定

- **现实世界（母界）**：当代华夏。存在保密级机构「国安九局·异界事务司」，专门处置超自然/跨界事件；民间不知情。
- **异界（玄沧界）**：修仙世界，灵气浓度约为母界 1100 倍。有妖兽、灵矿、宗门、上古秘境、丹药法宝。境界分"炼气—筑基—金丹—元婴—化神—炼虚—合体—大乘—渡劫"。
- **通道规则**：主角体内「万界摆渡系统」可开辟两界通道，每次穿越消耗"界能"；界能需现实侧物资（贵金属/能源）或异界灵气"充值"。活体/超凡物品带回母界受国家监管，不可私流通。
- **硬约束（防无限开挂）**：系统等级越高，单次搬运质量上限越高，但冷却与能耗同步上升；大乘以上（圣域级）不可带出，只能带"尸骸/遗物/功法残卷/灵材"。

## 3. 主角人设

- **姓名**：林默
- **年龄/身份**：22 岁，江城大学材料物理专业大四，课题组底层"工具人"，实验数据常被师兄冒领，保研无望、家境普通。
- **性格**：沉稳、轴、有家国底色的理工男；嘴上佛系，做事极狠；脑回路清奇（别人想称王，他想换编制）。
- **金手指觉醒契机**：雨夜从实验室回宿舍，被师兄嘲讽，掌心浮现"两界通道"印记，系统提示"绑定国家可获庇护"。
- **弱点（前期）**：肉身脆弱，异界初期只能靠智取 + 系统租赁的装备自保；不擅人情世故，常得罪人。
- **成长线**：穷学生 → 异界事务司特约研究员 → 国士无双 → 两界秩序重塑者。
- **声音特征**：内部独白自嘲、冷静、理工类比；句长 medium；语域 technical/folksy；被追问时 direct。

## 4. 核心冲突

- **外部·异界**：玄沧界顶级宗门「天罡宗」察觉跨界通道，圣子厉无咎跨界追杀，欲夺系统。
- **外部·境外**：西方秘密计划「深网（DeepNet）」侦测到异界资源，试图独占，与主角和国家争夺主导权。
- **内部·体制**：主角从"穷学生"到"国士"的身份跃迁伴随质疑、利益分配争议、旧势力阻挠（导师赵立德等）。
- **爽点主轴**：主角不断把异界宝贝上交 → 国家科技/战力跃迁 → 打脸曾轻视他的人与境外势力。

## 5. 爽点设计（节奏公式：打脸—升级—装逼）

- **小爽点（每 1–2 章）**：用异界灵材帮国家突破某技术瓶颈，让冒领成果的师兄/导师傻眼；用租赁的灵能装备在比试中碾压嘲讽者。
- **中爽点（每 3–5 章）**：一次性上交整条灵脉/古修士传承，国家立项"登神计划"，主角获国家级荣誉；境外阴谋被主角用异界手段反杀。
- **大高潮（每 8–12 章）**：天罡宗跨界大军压境，主角率"国械 + 灵能"混编军团反推异界，签城下之盟。
- **卷终决战（每 15–20 章）**：两界规则濒临崩溃，主角以"国家意志 + 系统终极形态"重塑秩序。

## 6. 节奏规划（长篇 · 约 140 章 · 五卷）

- **第一卷·觉醒与初次上交（1–25 章）**：系统觉醒 → 首穿玄沧界 → 带回灵材被国安九局收编 → 打脸师兄高彦与导师赵立德 → 建高校异界事务联络点。
- **第二卷·灵气兴国（26–55 章）**：以异界灵植/丹方助国家突破医药与材料卡脖子；境外 DeepNet 介入窃取。
- **第三卷·秘境争夺（56–85 章）**：上古秘境现世，多国跨界勘探，主角率国械灵能小队反制境外、夺核心传承。
- **第四卷·宗门反扑（86–115 章）**：天罡宗跨界，圣子厉无咎来袭，国械灵能军团成型，本土防御 + 反推异界。
- **第五卷·两界合一（116–140+ 章）**：两界规则崩溃，主角以国家意志 + 系统终极形态重塑秩序，华夏立万界之巅。

## 7. 配角框架

- **苏清漪**：国安九局异界事务司司长，冷艳干练，主角的体制内对接人，后期红颜。声音：短句、官方语域、被追问时 withholding（用"涉密"挡）。
- **秦振邦（秦老）**：国家顶尖材料学家，主角体制内引路人。声音：winding 长句、technical 语域、被追问时 overflow（话痨式科普）。
- **高彦**：林默师兄，冒领数据、嘲讽主角穷酸，前期打脸对象。声音：blunt 但虚伪、被追问时 deflect（甩锅）。
- **赵立德**：林默导师，想霸占主角上交成果，中期障碍。声音：official、被追问时 deflect。
- **厉无咎**：天罡宗圣子，骄傲冷酷，跨界追杀主角。声音：clipped 古风口吻、被追问时 direct（杀意直给）。
- **科尔森**：DeepNet 负责人，阴险，想独占异界。声音：medium、official 夹冷笑话、被追问时 deflect。

## 8. 开篇钩子（第一章预设）

雨夜，林默被师兄嘲讽，掌心浮现"两界通道"印记。第一次穿越坠入玄沧界荒野，被骨刺狼追杀；危急时系统弹窗："检测到宿主身处险境，建议将此界灵物上交母国以换取庇护——是否绑定国家？" 林默："绑定。" 绑定瞬间，母界国安九局雷达捕捉到跨界能量波动；同时玄沧界天罡宗探子感应到通道裂纹。
