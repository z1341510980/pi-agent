# Public-source, noncommercial baseline

This branch starts from commit `b257e008eb53bfbf2fa03e6c83836e538ab4c166` (`连续4篇100成功版本`).

The following materials were intentionally removed from the public export:

- `tmp/`: unpublished drafts, temporary scripts, and third-party report captures;
- `evals/`: raw evaluation fixtures, results, and run identifiers.

The removal is a privacy and publication-boundary decision. It does not replace the workflow with a later revision: `SKILL.md`, `agents/`, and the maintained `references/` tree originate from the stated baseline, except for the redaction below.

Four case files were minimally redacted for publication:

- `references/writer-case-shared-author-voice.md`;
- `references/detector-compatible-fiction-calibration.md`;
- `references/writer-case-local-dense-payoff.md`;
- `references/writer-case-overdesigned-chain.md`.

The redactions remove unpublished-story identifiers, quoted dialogue, report identifiers, exact report metrics, and window sizes. Their operational rules and evidence limitations remain intact.

Do not describe this export as a guarantee of literary quality, a detector benchmark, or a way to evade detection.
