# 人物形成过程缺失案例

只在关键变化从标签跳到结果、情绪悬空、人物只按固定属性运行，或公共细节与总结句替代具体经验时读取。案例用于识别关系，不提供可复制句式。

## 1. 背景标签不能独自完成眼前决定

### 失效关系

> 父亲在他小时候离开了家，所以他从不相信承诺。妻子让他签手术同意书，他沉默片刻，最终拒绝。

背景、性格和结果都齐全，但当前场景没有东西承担“为何此刻拒绝”。继续补父亲旧事，只会让解释更完整，选择仍然悬空。

### 重建关系

让眼前某个事实触发他的旧判断，并使选择付出代价：他注意到承诺上的哪一处措辞、误把谁的迟疑理解成什么、想保护什么，或签与不签分别会失去什么。只需一个有决定力的形成环节，不必补写全部童年。

### 反误学

次要行为、类型故事里的快速反应、前文已经充分建立的选择，不需要每次重新展开。省略中间心理不等于逻辑跳跃。

## 2. 情绪必须进入人物，而非只换一个名称

### 失效关系

> 她既委屈又愤怒，还有一种说不出的悲伤。她看着母亲，心里五味杂陈。

这里报告了情绪，却没有说明情绪怎样改变她正在经历的场景。换成更精确的词仍只是报告。

### 重建关系

保留或不保留情绪词都可以。关键是让它改变人物会先听见哪句话、故意忽略什么、把责任错推给谁、说到哪里停住、做出或放弃什么，以及关系因此留下什么后果。克制的人可能只改变一个称呼或不再完成原本的动作。

### 反误学

直接写“她很难过”可以准确有力；情绪也不必每次改变剧情。只要它已经改变感知、语言、动作或场景质地，就不需要另加表演。

## 3. 性格通过关系发生，不靠随机反差

### 失效关系

人物被设定为要强，于是面对老板、母亲、伴侣、陌生人和孩子都用同一种拒绝求助来证明要强；或几个人设标签不同，冲突时却依次准确说明问题、承认责任并达成成熟结论。

### 重建关系

保留稳定性格，让对象、利害、旧账和权力差异改变它的具体表现。他可能不肯向伴侣低头，却愿意向陌生人借钱，因为两种求助暴露的东西不同。差异必须能从关系中解释，不为“复杂”随机反常。

### 反误学

专业人物在职责范围内持续理性、一个人在巨大压力下仍保持原则、多人恰好达成共识，都可以真实成立。不要把一致、正确或克制本身视为AI味。

## 4. 具体经验不等于猎奇细节

### 失效关系

连续使用雨、红眼眶、颤抖的手表达悲伤，或用破衣服、粗糙双手、昏暗灯泡表达贫穷。这些细节并非错误；问题在于整组内容只标记类别，换掉人物和地点仍不改变意义。若随后旁白又宣布“他终于明白这就是爱”，具体经历会再次被结论覆盖。

### 重建关系

问这个人物因生活习惯、关系旧账或眼前目的，会偏偏注意、避开、误用、舍不得什么。具体不等于稀奇，也不要求细节成为象征或伏笔。已经由选择、动作或物件成立的意义，允许停在那里；确需点明时，让总结带来新的认识或选择，而不是复述。

### 反误学

雨、眼泪、旧衣服和点题句都可继续使用。判断对象是它们与人物经验的关系，不是词语新不新、常不常见。

## 修改顺序

1. 先确认正文要成立的关键变化是什么。
2. 找到现在承担它的是背景标签、情绪名称、人设属性还是公共符号。
3. 只重建一个真正必要的当前形成环节。
4. 删除变化成立后的重复总结或证明。
5. 整章通读，防止把原来的跳跃改成一条过于完整的心理流程。
