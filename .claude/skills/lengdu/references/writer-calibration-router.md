# 主作家三级校准路由

校准的用途是帮助成熟作家恢复判断，不是把实验结论变成写作公式。每次只加载能改变本次决策的最小材料。

本路由只管理主作家自身要读取多少历史经验。完整候选写成后，仍须执行独立的[作者侧零继承校准协议](blind-author-calibration-protocol.md)；主作家的一级、二级或三级自审都不能替代那个新Agent。

## 一级：日常轻量校准

适用于普通新写、续写和单次重写。固定读取：

1. `writer-profile-v0.3.md`；
2. `writer-current-risks.md`；
3. 当前项目事实与用户约束。

不默认读取完整历史案例、检测报告或旧稿。风险卡只在完整初稿完成后用于一次整体通读，不得逐句干预创作。

## 二级：针对性校准

出现以下任一信号时，除一级材料外，只读取一个最匹配的完整案例或反例：

- 用户、Reader或主Agent发现同一种作者惯性再次出现；
- 正文用背景或性格标签直接宣布重要转变，或核心情绪只被命名而没有改变人物的注意、动作与关系后果；
- 人物面对不同关系仍只按固定属性运行，或一组生活细节只能泛化地标记悲伤、贫穷、紧张与温暖；
- 正文能看懂也流畅，但像流程、方案演示或信息编排，人物不够活；
- 角色设定不同，临场对白却都冷静、准确、成熟，像共同替作者概括矛盾并完成关系修复；
- 主Agent准备把一次外部结果概括成“少写流程”“少解释”“多留白”等通用口令；
- 某个已经修过的问题在新题材中复发；
- 修改可能走向故意不清楚、故意留瑕疵或随机加生活细节。

选择方法：

- “关键转变从标签跳到结果、情绪悬空、人物只按固定属性运行、公共细节或总结句代替经验”读取`writer-case-formation-gap.md`；
- “信息过快就位、细节连续触发、人物轮流执行”读取`writer-case-overdesigned-chain.md`；
- “整章成立但一个局部同时完成设定补全、标准示范和情感兑现”读取`writer-case-local-dense-payoff.md`；
- “所有人物都太会说话、准确接话、迅速自省并共同抵达正确结论”读取`writer-case-shared-author-voice.md`；
- “想从一个案例直接归纳固定禁令”读取`writer-counterexamples.md`；
- 字面理解、对白接话、空间或道具连续性问题，读取`calibration-cases.md`中的对应一条。

二级校准只帮助找根因，不要求新稿复制案例的长度、题材、场景或解决办法。

## 三级：全量恢复

仅在以下情况使用：

- 模型或主作家实现发生明显切换；
- 连续两篇出现同类严重复发；
- 上下文漂移，主Agent已经把校准结论记成口号；
- 作家人格版本升级或正式批次验证；
- 用户明确要求系统复盘全部作者经验。

三级恢复读取全部作者校准材料与必要的高分辨率开发证据，重新区分：

- 哪些是已经跨文本复现的关系；
- 哪些只是单篇猜想；
- 哪些反例足以推翻简单公式；
- 哪些规则应该缩短、降级或删除。

完成恢复后，日常写作立即退回一级。不得让全量证据常驻每一篇正文的生成上下文。

## 校准升级纪律

新的作者经验必须经过三步才可进入日常风险卡：

1. 一个真实失败或明确用户反馈；
2. 同文本修改或重建后出现可观察改善；
3. 在陌生题材前向测试中仍能帮助写作，且没有伤害清楚、自然和好看。

单篇检测变化只能建立候选解释，不能独立建立通用规则。Reader通过也不能单独证明作者惯性已经消失。
