# 盲读子Agent协议

## 运行身份

每次Reader运行先完整读取[Reader v0.4](reader-profile-v0.4.md)。长期保存的是版本化Reader档案；实际执行者必须是`fork_turns="none"`的新Agent。不要调整模型能力来模拟普通人；应通过任务边界让它只做普通首读，不主动进行文学分析、逻辑审计或作者意图推演。不得复用读过旧稿、作者说明或修改目标的Agent。

## 隔离输入

Reader实例只能收到：

- Reader档案的精确路径；
- 当前唯一版本按原顺序切出的正文事件包；
- 事件包序号和最终`【全文结束】`标记。

不得提供作者说明、大纲、写作提示、用户反馈、主Agent怀疑位置、旧版本、修改记录、检测报告、样本标签、预期答案或相邻文件。任务名和临时文件名保持中性。

## 事件包分段

不要每句话切分，也不要一次暴露全文。每个新场景的第一包应让主要人物和眼前事情出现，但不要为了替作者补清来意而越过第一个自然小边界；Reader需要在这里完成一次开场落脚检查。其余事件包优先在一次小的阅读动作完整后切开，例如一轮对话落地、一个决定做出、一次行动出现结果、人物关系发生变化或场景切换。

使用软长度护栏保持不同文本间基本稳定：通常每包约400至800个汉字；不足200字时优先与相邻内容合并，超过1000字时优先在完整段落或对白轮次后拆开。语义完整优先于凑字数，不切断完整句子、对白轮次或尚未落地的决定。

分段只为保存首读状态，不得根据怀疑位置临时调整。普通描写与它所在的场景一起发送，不把单句抽出来诱导Reader挑错。

每次只发送一个事件包，等Reader返回状态后再发送下一包。Reader已经记录的第一次“要想一下”“开始扫”或“想停”必须保留。

## 启动任务

使用下列中性任务启动新实例：

```text
完整读取 <Reader档案精确路径>，只读取这一个档案，不浏览父目录、相邻文件或测试目录。你是该档案的本次干净实例，不知道作者意图、旧版本、修改目标和预期答案。

正文将按原顺序以事件包发送。请像平时看小说一样只读一遍，不主动回看、做文学分析或复杂逻辑推演。每次只依据目前已经收到的文字，严格使用档案中的输出格式。不得索取或浏览未发送的正文，不提供改写，不评价AI味或检测结果。收到【全文结束】前只返回当前事件包读感；收到后再给最终报告。
```

随后通过同一Agent依次发送：

```text
【正文事件包 n】
...
```

最后一个事件包末尾添加：

```text
【全文结束】
```

## 主Agent判定

- Reader只报告“看懂、流畅、好看”三项真实反应，不自动拥有修改决定权。
- Reader说“要想一下”已经说明表达提高了普通阅读成本，不要求它证明两条完整逻辑分支。
- Reader复述中若自行加入正文未落地的所有权、来意或因果，主Agent应检查它是否把“大概猜到”误报成“一眼懂”。
- Reader说“开始扫”或“不想看了”时必须给出第一次发生的位置和直接感受，不能只说“平淡”“不够爽”。
- 个人题材偏好不能迫使正文改成Reader自己的口味。
- 后文重新吸引Reader，不会抹掉前面已经发生的卡顿、扫读或弃读风险。
- 用户已经确认的困惑或无聊高于Reader漏检；应加入候选规则验证，而不是用Reader“通过”反驳用户。

## 信息泄漏审计

发送前确认：

- 只有一个正文版本；
- 当前Agent没有读过该版本、旧版或修改说明；
- 事件包保持原文顺序且连续；
- 没有问题暗示、用户结论、检测信息、样本极性或预期答案；
- 未向Reader暴露后续事件包、测试清单和相邻文件。

缺少零继承Agent或无法物理隔离后文时，只能标记“自审降级模式”，不得声称完成独立Reader验证。
