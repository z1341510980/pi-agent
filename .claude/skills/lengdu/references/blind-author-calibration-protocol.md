# 作者侧零继承校准协议

## 目的

在主作家完整写完当前候选后，用一个没有参与创作的新Agent双路检查：关键人物变化是否被背景、情绪或意义结论直接替代，以及正文是否被组织成过于完整的证明链与结算链。该结果是作者侧候选证据，不是Reader读感，也不是强制修改命令。

## 实例化

1. 每次校准启动一个`fork_turns="none"`的新Agent；不得复用主作家、普通Reader、旧校准者或任何看过开发讨论的Agent。
2. 只向新Agent发送[作者侧盲校准者 v0.2](author-calibrator-profile-v0.2.md)全文和当前唯一正文全文。
3. 任务名和提示保持中性，例如“阅读当前正文并按随附档案提交校准记录”。不要使用“逻辑跳跃”“情绪悬空”“首尾过密”“过度设计”“找出问题”等带答案的名称或提示。
4. 不让新Agent自行浏览Skill目录、项目目录或临时目录；正文和档案由主Agent直接提供。

## 严禁泄漏

不得向校准者提供或暗示：

- 故事大纲、作者意图和作者解释；
- 旧稿、修改过程、版本差异和历史案例；
- 用户已经指出的问题或主Agent的怀疑位置；
- 普通Reader的反馈；
- 朱雀或其他检测报告、比例、窗口、结果与猜想；
- 希望它命中的段落、方向或预期答案。

若任务上下文已经包含上述信息，不得继续冒充盲校准。换一个真正零继承的新Agent重新开始。

## 接收结果

校准者必须先划分自然叙事单元，再提交正文证据、候选关系与最小建议撤回范围。主Agent检查：

1. 引文是否真实存在且相邻关系准确；
2. 判断是否落在档案规定的A、B两路八类范围；
3. A路是否具体指出“正文结论—缺失形成关系”，并检查正文中是否已有足以承担变化的动作、选择或后果；
4. A4若命中，是否依据一组核心细节的可移植关系，而不是因为单个意象常见；若同处也命中B路，两种诊断是否确实指向不同修改决策；
5. B路是否把“功能多”“结局完整”或“人物真实变化”本身误判为问题；
6. 是否偷偷评价AI味、好看程度或提供改写。

越界内容作废，但不要求校准者重写正文。

## 主作家决策

- 校准命中只建立候选。主作家结合整章人物、关系和节奏决定采纳、缩小范围或不采纳。
- 若A路命中，只撤回承担该变化的最小自然叙事范围，从当前触发、人物注意、关系压力、迟疑、选择或代价中重建真正必要的一环；不得简单补人物简历、心理说明或更强的情绪词。
- 若B路命中，只撤回最小自然叙事范围，保留已经成立的正文；不得通过故意含混、随机枝节、逻辑瑕疵或删除必要因果来反向修正。
- 若人物变化真实，但同一次变化被多个动作重复证明，保留最能承担人物选择的一两个证据，是否重建其余部分仍由主作家决定。
- 若不采纳，记录简短理由即可，不要求把校准者说服成“没有问题”。
- 校准完成后，当前候选或重建稿必须交给另一个零继承的普通Reader，按Reader协议验证看懂、流畅和好看。不得把校准报告交给Reader。

无法启动零继承Agent时，只能标记“作者侧自审降级”，不得声称完成独立作者校准。
